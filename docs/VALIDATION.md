# 검증 기록 · 0.2.0

- Python unittest: 20개 통과. 종족별 생활 루프, 서버 저장, 재시작 복원, 기존 저장에 진행 기록 추가, 실패한 행동의 진행 미지급 포함.
- JavaScript 문법 검사 통과.
- 실제 클라이언트 컨트롤러를 최소 DOM 환경에서 실행: 도보/탑승 12개 목적지 도착, 자원 접근 후 채집, 정지 시 이동 취소, 안내 완료 검사 통과.
- Markdown 내부 링크와 필수 문서 검사 통과.
- 브라우저 시각/터치 QA는 미검증: 관리형 미리보기 실행 환경에 Python 런타임이 없어 서버를 시작하지 못함. 자동 검사 결과가 실제 브라우저 렌더링 검증을 대신하지는 않음.

## 로컬에서 확인할 항목

1. start.bat 또는 sh start.sh로 브라우저 열기.
2. 종족 선택 후 지도 자원 클릭 → 채집 → 아지트 귀환 → 시설 건설 → 제작/섭취.
3. 좁은 화면에서 지도 탭과 채집/공격 버튼 동작 확인.
4. 적 접근 후 공격, 탭 숨기기/복귀, 일시정지, 재시작 저장 복원 확인.

장식 지형은 통과 가능하며 경로 탐색, 자유 건축, 멀티플레이는 이 빌드에 포함되지 않습니다.
