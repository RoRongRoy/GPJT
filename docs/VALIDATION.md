# 검증 기록

작성일: 2026-10-26. 환경: Linux / Python 3.12.14 / Node 24.22.1.

## 통과

- Python 자동 테스트 17개: 게임 규칙 12, HTTP 4, 실제 서버 프로세스 재시작 통합 1.
- `node --check public/app.js`: 문법 검사.
- `python tools/check_docs.py`: 로컬 Markdown 링크와 필수 파일 존재 검사.
- 실제 서버 프로세스에서 인간 선택→주방→요리→의료실→뱀파이어→연금대→강화혈액→인간 복귀→강화→아지트 이동→일시정지 후 종료/재시작. 자산·종족·revision·정지 상태 복구 검사.

## 미검증

실제 브라우저 UI 조작·시각 QA를 완료하지 못했습니다. Playwright 패키지는 있었으나 Chromium 실행 파일이 없었고, 설치 다운로드가 손상된 응답으로 실패했습니다. 화면이 검증 완료되었다고 주장하지 않습니다. 수동 시나리오는 TEST_PLAN에 있으며 개인 PC의 브라우저에서 먼저 실행해야 합니다.

Windows start.bat 실행, 개인 PC 외부 HTTPS 링크 접속, 공유기/회선, 장시간 부하, 멀티는 미검증입니다. 자동 테스트 통과가 이러한 검증을 대체하지 않습니다.
