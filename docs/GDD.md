# BLOODFALL: 격리구역

게임 디자인 문서 v0.7 · 2026-10-26 · 가제

> 무너진 도시에서 인간과 뱀파이어가 생존 자원을 두고 싸운다. 어느 쪽도 감염으로부터 안전하지 않으며, 오늘의 적이 내일 같은 종족이 될 수 있다.

이 문서는 초기 콘셉트와 시스템 규칙을 연결하는 설계 초안이다. 사용자 결정은 2D 쿼터뷰, 싱글플레이 우선, 향후 소규모 멀티, 양 진영 NPC, 넉넉한 주문서 수급을 통한 강화, 생존·하우징 중심, 인간의 요리와 뱀파이어의 강화혈액 생산, 종족 복귀와 아지트 보존, 시즌 없음, 과금 없음, 링크로 접속하는 웹게임과 제작자 개인 PC 서버 운영이다. 멀티 인원·기술 스택과 수치는 개발 및 플레이테스트를 위한 제안값이며 확정 사양이 아니다. 언급된 게임들은 사용자가 제시한 경험의 방향을 뜻하며, 현행 게임 사양을 조사하거나 그대로 재현한 문서가 아니다.

## 1. 게임 개요와 핵심 경험

| 항목 | 제안 |
| --- | --- |
| 장르 | 싱글플레이 중심 진영 기반 오픈월드 생존 제작 RPG |
| 플랫폼 / 시점 | 설치 없이 URL로 접속하는 웹브라우저 게임, 2D 쿼터뷰·고정 사선 카메라; 데스크톱 조작 우선 제안 |
| 세계 | 현대 문명 붕괴 이후의 도시·농촌·산업지대·항만 |
| 플레이어 진영 | 인간 연합 / 뱀파이어 혈족, 2개 |
| 공통 위협 | 좀비·강화좀비·돌연변이·감염된 뱀파이어 |
| 세션 구조 | 제작자 개인 PC의 게임 서버와 저장소, 브라우저 클라이언트. 1인 플레이 우선, 이후 소규모 동시 접속 |
| 규모 가정 | 출시 핵심은 1인 완결; 향후 2~4인 제안, 최대 인원은 미확정 |
| 파티 | 혼자 모든 핵심 콘텐츠 공략 가능, NPC 동행 1명 제안; 멀티는 선택 확장 |
| 플레이 시간 | 일상 활동 20~40분, 고위험 원정 40~60분 |
| 핵심 동기 | 식량·혈액 자급, 요리·연금술, 농사·저장, 아지트 확장·꾸미기, 생활 시설 성장 |
| 운영 원칙 | 시즌 없음, 정기 초기화 없음, 게임 내 과금 없음 |

플레이의 중심은 ‘내 아지트에서 오래 살아갈 생활 기반을 만들고, 더 편리하고 풍요롭게 가꾸는 것’이다. 식재료·혈액 확보 → 요리·연금술 → 생존과 원정 준비 → 재료 탐색 → 저장·생산·건축 개선이 중심 루프다. 진영 전투·약탈·던전은 생활 성장에 필요한 자원과 선택적 도전을 제공한다. 전쟁 참여나 매주 던전 소진을 기본 생활의 유지 조건으로 두지 않는다.

### 설계 원칙

1. 인간과 뱀파이어 모두 단독 생존이 가능하되 전투 방식과 자원 수요가 다르다.
2. 좋은 재료에는 이동과 반출 위험이 따른다. 희귀도를 올리는 것만으로 성장을 만들지 않는다.
3. 감염은 실제 변화를 일으킨다. 다만 복구 수단 없는 영구 박탈은 피한다.
4. 하우징에 쏟은 시간과 현장에 들고 나온 화물은 다른 수준으로 보호한다.
5. 주간 제한은 최고급 성장 속도를 조절하며, 일반적인 사냥·제작·거래를 막지 않는다.
6. 농사·요리·연금술·하우징은 핵심 콘텐츠다. 일반 생존 자원을 자급할 수 있고, 상위 원정은 더 좋은 설비와 선택적 장비를 제공한다.
7. 진영 전쟁·거래·약탈·던전·치료는 다른 플레이어가 없어도 완결된다.
8. 강화 주문서는 일반 활동에서 충분히 공급한다. 강화 시도 부족과 장비 파괴로 반복 노동을 강요하지 않는다.
9. 종족 변화는 되돌릴 수 있고, 아지트와 생활 자산은 유지한다. 시즌·정기 초기화·과금은 도입하지 않는다.

## 3. 세계관과 진영

혈액 재생 기술로 확산된 혈화 현상은 뱀파이어를 만들었고, 이후 발생한 별개의 괴사성 병원체는 인간과 뱀파이어 모두를 좀비로 바꾸었다. 두 집단은 병원·발전소·혈액 저장고·정수장을 차지하려 싸우지만, 감염 중심부에 접근하려면 같은 위협을 상대해야 한다.

### 인간 연합

- 전투: 총기·정찰·설치형 장비·엄폐·치료에 강점.
- 생존: 음식·식수를 꾸준히 확보하고 재배·사냥·정수·요리로 식생활을 유지한다. 체온과 피로도 관리한다.
- 거점: 작업대, 정수기, 발전기, 의료실, 통신실, 동료 숙소.
- 특수 행동: UV 장비, 감염 진단, 정화 절차 실행.
- 약점: 보급이 끊기면 장기 교전이 어려우며 근접 기습 대응이 중요하다.

### 뱀파이어 혈족

- 전투: 근접 압박·추적·짧은 기동·혈액을 사용하는 회복에 강점.
- 생존: 혈액을 지속적으로 확보하고 연금술로 강화혈액을 만들어 혈액량과 혈액 안정도를 유지한다. 강화혈액은 인간의 요리에 대응하는 일상 소모품이다. 직접적인 음식·갈증 게이지는 없으며 물과 작물은 연금술·종복 식량·시설 생산에 사용한다.
- 거점: 관, 혈액 보관실, 연금 작업대, 차광 설비, 종복 숙소. 전력과 전자 시설도 사용 가능.
- 특수 행동: 흡혈, 혈흔 추적, 제한적인 혈화 전염.
- 약점: 햇빛과 UV에 노출되면 안정도 감소 및 회복 제한. 차광 장비로 낮 활동 가능.

진영별 전용 수단은 있지만 필수 자원의 독점은 두지 않는다. 기본 혈액은 비감염 동물 채혈·혈액 보관소 탐색·혈액상 거래·파견으로 확보할 수 있어 사람을 공격하지 않아도 생존 가능하다. 감염체의 혈액은 일반 생존용으로 바로 마실 수 없고 정제 또는 연구 재료로 사용한다. 인간도 야간 조명·감지 도구로 대응할 수 있다. 낮과 밤은 전술을 바꾸되 어느 진영도 절반의 시간을 접속 불가 수준으로 만들지 않는다.

### 양 진영 NPC 세력

인간과 뱀파이어 모두 정착지, 지도자, 상인, 의뢰 담당자, 치료 담당자, 경비, 순찰대, 교역대를 갖는다. 모집 NPC만 존재하는 것이 아니라 플레이어와 무관하게 살아가는 두 세력이 월드의 갈등을 만든다.

| 역할 | 인간 예시 | 뱀파이어 예시 | 플레이 |
| --- | --- | --- | --- |
| 지도자·의뢰 | 생존자 지휘관 | 혈족 장로 | 진영 퀘스트·평판·전초기지 목표 |
| 상인·제작자 | 보급관·총포 기술자 | 혈액상·혈인 장인 | 자원·장비·주문서 거래 |
| 치료자 | 의무관·정화사 | 혈의술사 | 감염 치료·정화·혈화 해제 |
| 전투 인원 | 정찰병·사수·정화병 | 추적자·혈기사·혈술사 | 순찰·매복·방어·전환 위협 |
| 비전투 인원 | 농부·운반인·생존자 | 관리인·운반인·혈족 주민 | 구조·납품·모집 |
| 운송대 | 보급 차량대 | 혈액·유물 운송대 | 호송 또는 약탈 |

NPC 관계는 종족과 진영 평판, 범죄 상태로 판정한다. 같은 진영은 기본 우호, 반대 진영 전투원은 분쟁 지역에서 적대, 중립 상인과 휴전 지점에서는 거래 가능하다. 민간인 공격은 평판·범죄 불이익을 준다. 적대 진영을 없애야만 진행 가능한 퀘스트는 두지 않는다.

진영 AI는 정착지 보급 상태에 따라 순찰·교역·전초기지 공격 이벤트를 선택한다. 소규모 분대와 정해진 경로부터 구현하며 월드 전체 NPC의 실시간 생활 시뮬레이션은 목표로 하지 않는다. 화면 밖은 간단한 상태 갱신, 가까운 구역만 상세 AI로 동작한다. 본거지는 쉽게 소멸하지 않고 전초기지만 점령이 바뀌어 콘텐츠 고갈을 막는다.

일반 전투 NPC도 좀비에게 물리면 감염되며 뱀파이어 NPC도 좀비화한다. 지정된 전환 가능 NPC는 혈화·정화를 통해 종족이 바뀔 수 있다. 전환이 곧 자동 모집을 뜻하지는 않으며 신뢰·구조·계약 조건이 필요하다. 필수 상인과 치료자는 보호 구역 또는 대체 인력으로 기능을 유지해 진행이 막히지 않도록 한다. 인간 정화병과 뱀파이어 혈화 적은 플레이어에게도 기존 전환 규칙을 적용한다.

## 4. 플레이 루프와 성장

### 기본 루프

아지트에서 농작물·식수·혈액 재고 확인 → 요리 또는 강화혈액 제작·섭취 → 파견과 생산 예약 → 필요한 재료를 채집·탐색 → 귀환·정리·치료 → 시설 확장·배치·꾸미기 → 다음 생활 주기 준비. 전투·교역·약탈·던전은 목표 재료에 따라 선택한다.

### 단계별 경험

| 단계 | 목표 | 주요 활동 | 거점 성장 |
| --- | --- | --- | --- |
| 생존 정착 | 하룻밤 버티기 | 물 확보, 식량, 붕대, 임시 무기 | 깃발, 침상/관, 빗물통, 작업대 |
| 자급 기반 | 원정 비용 줄이기 | 농사, 해체, 구급, 동료 구조 | 농장, 정수, 숙소, 저장고 |
| 산업화 | 위험 지역 준비 | 합금·전자 부품·연료 파밍 | 발전, 의료, 가공, 차광 |
| 고위험 성장 | 상위 설계와 시설 확보 | 주간 던전, 호송, 분쟁 | 고급 제작, 격리, 통신 |
| 생활 고도화 | 편리한 자급 생활과 아지트 완성 | 고급 요리·혈액 연구, 건축·장식, 선택적 GPU 원정·교역 | 냉장·냉각, 생산 자동화, 채굴장, 주거 공간 |

캐릭터 성장은 전투 숙련·생활 숙련·설계 해금으로 구분한다. 종족이 바뀌어도 공용 성장과 연구는 보존하고, 종족 전용 기술만 비활성화/활성화한다. 장비는 일방적 수치 상승뿐 아니라 소음·기동·보호·적재량의 교환 관계를 갖는다.

### 장비 강화: 주문서를 넉넉히 얻고 자주 시도하는 성장

강화는 무기·방어구에 적용하며 시설 레벨업과 구분한다. 인간의 총기·근접 무기와 뱀파이어의 무기·혈술 촉매 모두 지원한다. 주문서는 무기용/방어구용 두 종류로 단순화하고 진영 전용 주문서를 따로 요구하지 않는다. 초기 상한은 +10 제안이다.

| 구간 | 성공률 제안 | 시도당 주문서 | 실패 결과 | 역할 |
| --- | --- | --- | --- | --- |
| +0→+3 | 100% | 1장 | 실패 없음 | 초반부터 즉각적인 성장 |
| +3→+6 | 80% | 2장 | 단계 유지, 2회 연속 실패 후 다음 시도 확정 | 자주 시도하는 중반 성장 |
| +6→+9 | 60% | 3장 | 단계 유지, 3회 연속 실패 후 다음 시도 확정 | 선호 장비 투자 |
| +9→+10 | 40% | 5장 | 단계 유지, 4회 연속 실패 후 다음 시도 확정 | 최종 완성 |

장비 파괴·강화 하락은 없다. 실패 시 해당 시도의 주문서와 소액 크레딧만 소비한다. 실패 누적은 장비별 현재 단계에 저장하고 성공 시 초기화한다. 성공 확률·현재 누적·확정까지 남은 실패 횟수를 UI에 공개한다. 확정 시도에도 동일 비용을 쓰며 게임 종료로 누적이 사라지지 않는다.

강화 효과는 기본 공격/방어 수치에 단계당 +2%, +10에서 +20%를 출발점으로 삼는다. 공격속도·이동속도·감염 확률까지 동시에 올리지 않아 강화만으로 모든 전술을 대체하지 않는다. 장비 등급은 기본 성능과 옵션, 강화는 그 장비에 대한 투자로 구분한다. 기본 스토리·필수 던전은 최고 강화가 없어도 완료할 수 있어야 한다.

### 주문서 수급과 비용 기준

- 일반 몬스터·좀비·진영 전투원·상자에서 흔하게 획득한다. 특정 주간 던전 독점 재료로 두지 않는다.
- 일반/반복 의뢰는 주문서 선택 상자를 확정 지급한다. 주간 의뢰는 추가 묶음을 제공한다.
- 파견에서도 소량 수급하고, 상인에게 소액 크레딧으로 보충할 수 있다. 주문서 구매에는 주간 횟수 제한을 두지 않는다.
- 기본 목표는 30~40분 일반 파밍+의뢰로 원하는 종류의 주문서 15~25장. 모든 획득처 합계 기준이며 실제 드롭률은 테스트로 조정한다.
- +0→+6은 평균 약 10.4장, 최악의 연속 실패에서도 최대 21장으로 설정된다. 초중반에 주력 장비 하나를 빠르게 강화할 수 있고 남는 주문서를 교체 장비·동료 장비에 사용한다.
- 소액 크레딧 비용은 같은 활동의 수리·치료비 차감 후에도 여러 번 시도할 수 있게 맞춘다. 희귀 촉매·주간 재료를 추가로 요구해 주문서의 풍부함을 무효화하지 않는다.

작업대 Lv.1부터 강화 UI를 제공하고 시설 상위 레벨은 비용 효율을 높이는 보너스로 둔다. 강화 시도 자체를 최고급 시설로 막지 않는다. 같은 장비 분류 안에서는 소액 비용으로 강화 단계와 실패 누적을 계승할 수 있으며 원본 강화는 +0으로 초기화한다. 원본과 대상 장비를 함께 저장해 복제되지 않게 하고, 전환으로 사용할 수 없어진 장비도 대응 분류로 계승할 수 있다. 강화된 NPC 지급 장비는 플레이어 보유 장비를 장착시키는 방식이며 NPC를 통한 무한 생성은 허용하지 않는다.

### 첫 60분 예시

0~10분: 진영 선택, 이동·전투·물림 회피 학습. 10~25분: 첫 깃발, 물 공급, 기본 제작. 25~40분: 소규모 탐색과 감염 억제 튜토리얼. 40~60분: 첫 동료/종복 확보, 교역소 귀환, 분쟁 지역의 위험 안내. 강제 진영 전환은 튜토리얼과 정착 구역에서 발생하지 않는다.

## 5. 월드와 위험 구역

| 구역 | 전투 | 사망 손실 | 거점 규칙 | 파밍 |
| --- | --- | --- | --- | --- |
| 보호 정착지 | 플레이어 공격 불가 | PvE 사망 시 일반 화물 일부 | 개인 거점 보호 | 기초 자원 |
| 분쟁 지역 | 적대 진영 NPC 전투; 향후 PvP 설정 적용 | 운반 중 일반 자원·화물 전부, 장비 내구도 손실 | 개인 핵심 시설 보호 | 중급 자원·필드 희귀품 |
| 봉쇄 지역 | 진영 NPC + 고위험 감염체 | 일반 화물 전부, 장비 추가 손실은 선택 난이도에서 검증 | 영구 거점 불가 | GPU·희귀 전자품·특수 시약 |
| 전쟁 구역 | NPC 전초기지 공격·방어 | 분쟁 규칙 + 공성 보급 손실 | NPC 전초기지 방어 시설·보급 창고 공격 가능 | 전략 자원 |

기본 난이도에서 착용 장비는 사망 시 유지하고 내구도만 하락한다. 전리품 약탈의 중심은 일반 인벤토리와 운송 화물이다. 보호 슬롯은 소량의 귀속 치료·퀘스트 물품 전용이며 거래 가능한 희귀 화물은 넣을 수 없다.

병원은 시약, 경찰서는 무기 부품, 산업단지는 기계, 연구소는 전자·변이 샘플, 항만은 무역 화물 공급처다. 한 지점을 봉쇄해 월드 진행을 막지 않도록 핵심 자원을 여러 지역에 분산한다. 강한 적은 위험 증가와 소음 누적을 통해 등장하고, 단순 접속 인원 증가만으로 무한 공급하지 않는다.

## 6. 전투·몬스터

기본 전투는 2D 쿼터뷰에서 방향 조준, 근접 공격, 회피, 스태미나, 부위별 방어로 구성한다. WASD 이동과 마우스 방향 조준을 기본 조작안으로 하며, 사거리·공격 부채꼴·물림 전조를 바닥 표시와 캐릭터 동작으로 전달한다. 총격은 캐릭터의 시야와 장애물 차폐를 판정하고, 근접 공격과 뱀파이어 돌진도 벽을 관통하지 않는다. 층이 다른 적은 자동으로 조준하지 않으며, 층간 공격 허용 범위는 별도 검증한다. 물림은 모든 공격에 무작위로 붙지 않는다. 잡기·경직·다운 상태 등 명확한 전조와 대응 기회가 있는 별도 공격이다. NPC 전투와 향후 PvP에서는 장시간 일방 구속을 막기 위해 구속 저항이 누적된다.

| 적 | 행동 | 대응 | 보상 |
| --- | --- | --- | --- |
| 일반 좀비 | 소음 추적, 근접 군집 | 은신, 우회, 군집 분산 | 기초 자원 |
| 강화좀비 | 돌진, 장갑, 강한 잡기 | 약점 노출 유도, 회피 | 합성 재료·조직 |
| 돌연변이 | 포자·원거리 오염·지역 봉쇄 | 방호와 역할 분담 | 시약·특수 재료 |
| 감염 뱀파이어 | 빠른 도약과 혈흔 추적 | UV·기동 제한 | 혈화 안정화 재료 |
| 지역 보스 | 소음·이벤트 조건으로 출현 | 협동 또는 경쟁 반출 | 시설 부품·설계 단서 |

총성·발전기·차량은 소음을 발생시킨다. 소음은 좀비·진영 NPC와 향후 멀티 플레이어에게 활동의 단서를 제공하지만, 전 월드에 항상 정확한 위치를 공개하지 않는다.

### 종족별 이동수단과 성장

인간은 오토바이 → 험비 → 상위 차량으로 발전한다. 뱀파이어는 변신술을 해금해 박쥐 → 거대박쥐 → 상위 변신 형태로 발전한다. ‘변신술’은 별도 탈것 단계가 아니라 뱀파이어 이동 계열의 시스템명으로 해석한다. 상위 단계의 이름과 외형은 미정이다. 아래 적재·연료·해금 조건은 초기 제안이다.

| 진영·단계 | 이동수단 | 주요 용도 | 부담·성장 방향 |
| --- | --- | --- | --- |
| 인간 초기 | 오토바이 | 빠른 단독 탐색·소량 재료 회수 | 적은 적재량, 연료·수리 필요 |
| 인간 중기 | 험비 | 장거리 탐색·대량 재료·NPC 동행 | 넓은 적재 공간, 연료 소비·소음 증가 |
| 인간 후기 | 상위 차량(미정) | 원정 거리·적재·방호·편의의 고도화 | 단순 속도 상승보다 생활 운송 효율 향상 |
| 뱀파이어 초기 | 박쥐 변신 | 단독 탐색·우회·귀환 | 혈액 소모, 기본 휴대품 유지, 대형 화물 불가 |
| 뱀파이어 중기 | 거대박쥐 변신 | 장거리 비행·확장 적재 | 혈액 소비 증가, 운반구 해금으로 화물 운송 |
| 뱀파이어 후기 | 상위 변신 형태(미정) | 항속·운반·안정성·편의의 고도화 | 연금술과 변신 숙련으로 유지 효율 향상 |

인간은 도로 이동과 적재량, 뱀파이어는 비행 경로와 지형 우회에 강점을 둔다. 같은 성장 단계에서 생활 자원 확보·귀환의 전체 효율은 비슷하게 맞추며, 뱀파이어가 화물 운송 콘텐츠를 사용할 수 없는 구조는 피한다. 거대박쥐의 동료 탑승 여부와 최대 인원은 후속 검증 항목이다.

### 해금과 아지트 시설

인간은 정비 관련 생활 퀘스트·차량 부품 회수·수리로 첫 오토바이를 마련하고, 차고와 정비대 성장으로 험비·상위 차량을 해금한다. 뱀파이어는 혈족 생활 의뢰와 기본 의식으로 박쥐 변신술을 익히고, 연금대·변신 연구 설비의 성장으로 거대박쥐·상위 형태를 해금한다. 첫 이동수단과 기본 유지 자원은 주간 던전·PvP 승리를 요구하지 않는다.

인간의 차고는 보관·급유·수리·적재 정리를, 뱀파이어의 변신 연구 설비는 형태 해금·항속 개선·운반구 관리를 지원한다. 두 계열 모두 일반 탐색·생활 의뢰로 성장하며 최종 부품·레시피는 선택적 고위험 원정의 보상이 될 수 있다. 장비 강화 주문서와 이동수단 연구는 별도 성장 체계로 두어 기존 강화 수급을 잠식하지 않는다.

### 소모·조작·비행 규칙

- 인간 차량은 연료와 내구도를 사용한다. 주행 거리·부하로 소모하고 엔진이 꺼진 상태에서는 연료가 줄지 않는다. 초기에는 단순한 탑승·하차·급유·수리부터 구현한다.
- 뱀파이어 변신은 시작 비용과 이동 중 혈액 소모를 가진다. 혈액 안정도는 기존 생활 규칙을 따르고 변신만으로 이중 급감시키지 않는다. 강화혈액은 비행 전 보급에도 쓰이지만 별도의 희귀 비행 전용 소모품을 필수로 요구하지 않는다.
- 연료·혈액 부족을 미리 알리고 차량은 정지, 박쥐는 가까운 유효 착지 지점으로 내려오도록 한다. 부족만으로 즉사하거나 지형 속에 갇히지 않는다. 차량은 현장 급유·수리, 변신은 착지 후 혈액 섭취로 다시 이동한다.
- 2D 쿼터뷰 비행은 타일별 통과·착지 가능 속성으로 표현한다. 낮은 장애물은 우회할 수 있지만 던전 경계·닫힌 실내·월드 경계는 관통하지 않는다. 공중 시야도 별도 판정하며 비행만으로 실내 적과 아이템을 모두 공개하지 않는다.
- 이동 형태가 무적 회피 수단이 되지 않도록 탑승·변신에 짧은 전조를 주고 위험 지역에서는 적의 탐지·공격 대상이 된다. 전투 기술과 이동 형태의 전환 시간은 후속 밸런스 항목이다. 박쥐의 실내 상호작용·제작은 착지와 변신 해제 후 수행한다.
- 휴대품은 변신한다고 삭제되지 않는다. 적재 한도를 넘으면 변신 전 안내하고 정리를 요구한다. 교역 운반구의 화물은 착지 지점에 남겨 변신 해제 때 기본 휴대 한도를 넘는 화물을 숨길 수 없게 한다. 비행도 실제 경로를 이동하므로 교역 화물의 순간이동 금지와 충돌하지 않는다.

### 종족 변화·저장 연계

종족이 바뀌어도 보유 차량·차고·연구 설비·변신 해금 기록은 유지한다. 현재 종족에 맞는 이동 계열을 활성화하고 원래 종족으로 복귀하면 기존 해금과 업그레이드를 다시 이용한다. 변신·탑승 중 종족 전환이 완료되면 유효 지점에서 안전 착지·하차 후 처리한다. 새 종족의 기본 이동수단 해금 경로를 안내하되 이전 자산을 소멸시키지 않는다.

차량 위치·연료·내구도·적재품, 변신 해금·운반구·형태 상태를 서버에 저장한다. 연결이 끊기거나 재시작될 때 공중에 고립되지 않도록 마지막 유효 착지 지점을 기록하고 동일 아이템을 중복 생성하지 않는다. 아지트의 즉시 이동은 유지하며 월드에서 운행 중인 차량·비행 중인 캐릭터·교역 화물을 함께 순간이동시키지는 않는다.

## 7. 감염·혈화·정화: 핵심 차별점

### 서로 다른 상태를 분리

- 종족 R: 인간 또는 뱀파이어.
- 좀비 감염도 Z: 0~100, 양 종족에 동일하게 존재.
- 혈화 상태 V: 인간의 뱀파이어화 진행. 뱀파이어는 재혈화되지 않는다.
- 정치 소속 F: 진영 평판·정착지 접근 권한·계약. 종족 전환 후 유예 절차를 통해 정리한다.

좀비화는 제3의 영구 플레이어 진영이 아니다. 2진영 구조를 유지하며, 통제 상실과 회복을 포함하는 위기 상태로 처리한다.

### 좀비 감염 진행: 초기 테스트값

| 감염도 | 상태 | 결과 | 대응 |
| --- | --- | --- | --- |
| 0 | 정상 | 제약 없음 | 보호구·회피 |
| 1~29 | 잠복 | 경고와 가벼운 증상 | 소독·조기 치료 |
| 30~59 | 발병 | 스태미나 회복 저하 | 억제제·의료 거점 |
| 60~89 | 중증 | 소음성 발작·치유 효율 저하 | 고급 치료 과정 |
| 90~99 | 임계 | 변이 예고와 귀환 경고 | 긴급 격리·구조 |
| 100 | 좀비화 | 현재 육체 통제 상실 | 복구 진료 후 재진입 |

확정 물림은 감염을 부여하되 보호구가 누적량을 줄인다. 기본 목표는 추가 피격이 없을 때 최초 감염부터 통제 상실까지 활동 시간 약 60~90분이며, 억제제로 진행을 멈출 수 있다. 최종 속도는 싱글 플레이테스트로 조정한다. 일시정지·안전 로그아웃 후에는 감염이 진행하지 않으며 감염·혈화 상태는 사망과 저장/불러오기로 삭제되지 않는다. 저장된 상태와 남은 시간을 그대로 복원한다. 향후 멀티의 전투 중 이탈 처리는 별도로 검증한다.

### 좀비화 이후

감염도 100 도달 → 월드 시뮬레이션이 육체와 일반 화물을 가진 감염체 생성 → 플레이어는 치료소 복구 화면 진입 → 확보한 치료제를 쓰거나 구조 계약을 진행 → 원래 종족으로 복구, 일반 화물은 자동 반환하지 않음.

감염체를 생성한 시점에 해당 화물의 소유권을 한 번만 이전한다. 회수 전 죽거나 이탈해도 복제가 발생하지 않아야 한다. 자신의 감염체에서 나온 생체 재료는 판매·반복 파밍 보상에서 제외한다. 튜토리얼 이후 첫 복구에는 안내용 지원을 제공한다.

### 치료의 난도

조기 감염은 일반 치료로 해소 가능하다. 중증 치료는 병원 시약 + 변이 샘플 + 의료실 레벨 2 이상을 요구한다. 뱀파이어는 추가 혈액 안정제가 필요하다. 억제제는 치료가 아니며 반복 사용 시 효율이 낮아진다. 회복 때문에 주간 던전 입장권을 반드시 소모하게 만들지 않는다.

시설과 돈을 모두 잃어도 중립 치료소의 구조 임무와 후불 치료 계약으로 복귀할 수 있다. 계약은 이후 게임 내 수입 일부로 상환하며, 현금 결제나 다른 플레이어의 선의가 복구의 필수 조건이 되어서는 안 된다.

### 뱀파이어 물림과 인간의 혈화

일반 흡혈은 혈액 회복 행동이며, 혈화 물림은 별도 재료·조건·시전 시간을 갖는 전환 행동이다. 분쟁 지역에서 다운된 인간에게 혈화 물림이 성공하면 V가 시작된다. 즉시 진영이 바뀌지 않고 활동 시간 60분의 치료 유예를 준다. 기한 안에 항혈화 치료를 마치면 인간 유지, 실패하면 뱀파이어로 전환된다. PvE 혈화 적도 같은 경고와 치료 규칙을 사용한다.

### 인간의 뱀파이어 정화

분쟁 지역에서 다운된 뱀파이어에게 정화 표식을 부여한다. 희귀 촉매 소모, 8초 시전, 방해 시 중단을 초기안으로 둔다. 표식은 활동 시간 60분간 정화 상태를 진행시키며, 혈족 거점의 해제 의식으로 저지할 수 있다. 기한이 지나면 인간으로 전환한다. 동의한 뱀파이어는 인간 의료 거점에서 자발적 정화를 받을 수 있다.

### 전환 이후 처리

- 강제 전환 뒤 활동 시간 2시간은 적응 지원 기간이다. 원래 종족 복귀 임무 또는 새 종족 수용을 선택하며, 기간이 지나거나 새 종족을 수용해도 나중에 복귀할 수 있다. 영구 종족 잠금은 없다.
- 적응 기간에는 적대 진영 본거지·진영 보급 창고·점령 보상 접근 금지. 개인 치료와 거점은 이용 가능.
- 전환 처리 시 기존 진영 보급 이용과 의뢰 수령 권한을 중지한다. 개인 시설과 NPC의 기존 작업은 보존한다. 같은 종족으로 복귀하면 이전 진영 권한을 복구할 수 있다. 향후 멀티의 공유 권한은 별도로 관리한다.
- 새 종족을 수용하면 기존 진영 관계 재평가 및 진영 계약 정산. 이미 잠근 주간 보상 횟수는 그대로 유지한다.
- 아지트 위치·건물·시설 레벨·창고·가구·농작물·고용 NPC·생산 진행 상태를 유지한다. 주방과 연금대는 함께 보유할 수 있으며 종족 변화로 철거하거나 초기화하지 않는다. 침상/관 등 필요한 설비는 변환 또는 추가 설치로 대응하고 종족 전용 장비에는 임시 대체 장비를 제공한다. 종족 변화만으로 고용 NPC를 잃지는 않는다.
- 전환·복귀 후 게임 내 3일 동안 적대 NPC와 향후 PvP의 추가 종족 전환 면역. 좀비 감염과 일반 전투 피해는 별개다.
- 좀비 감염과 혈화/정화가 겹치면 임계 좀비화가 우선한다. 의료 복구가 끝날 때까지 종족 전환 타이머를 정지하고 복구 후 남은 시간을 재개한다.
- 보호 정착지와 튜토리얼에서 적대 전환 불가. 강제 전환 보상은 반복 살해보다 더 엄격하게 동일 대상 보상 제한.

### 언제든 가능한 종족 복귀

혈화된 인간은 정화 치료로, 인간화된 뱀파이어는 복귀용 혈화 의식으로 이전 종족에 돌아갈 수 있다. 감염·전환 이력을 저장해 치료 NPC가 맞는 경로를 제공한다. 과정은 재료 수집·치료 퀘스트를 요구하지만 주간 한정 재료나 상대 진영의 영구 적대 때문에 막히지 않도록 중립 치료소에 대체 경로를 둔다. 복귀 기한·횟수 제한은 두지 않고, 기존 적대 전환 면역은 자발적 복귀를 막지 않는다.

전환 직후에는 새 종족용 기본 음식 또는 강화혈액과 간단한 조합식을 제공해 생산 설비를 준비할 시간을 준다. 좀비화 역시 기존 치료·복구 절차로 돌아올 수 있다. 종족 변화는 새로운 생활 방식을 경험하는 사건이며 아지트를 다시 짓는 처벌이 아니다.

## 8. 하우징·깃발·거점 이동

개인 거점은 월드 내 플레이어당 1개를 기본으로 한다. 개인 깃발은 건축 영역과 소유권을 설정한다. NPC 전초기지는 월드의 고정 목표이며 아지트 이동 대상이 아니다. 길드 시스템은 기본 범위에서 제외한다.

개인 거점에서는 타일 그리드를 기준으로 벽·문·수납·생산·생활 장식을 자유롭게 배치한다. 바닥과 시설 점유 칸을 미리 보여주고, 문·계단·통로가 막히면 경고한다. 층별 건축을 지원하는 방향으로 설계하되 MVP는 단층에 집중한다. 도로, 주요 파밍 지점, 던전 입구, 다른 깃발 주변에는 설치할 수 없다. 영구 설치는 지형과 충돌 검사를 통과해야 한다.

### 아지트 즉시 이동 규칙

1. 플레이어가 설치 가능한 새 위치에서 깃발 배치 미리보기를 확인하고 확정하면 아지트 전체를 즉시 이동한다.
2. 건물·시설 레벨·가구·창고의 모든 일반 물품·보관 중인 GPU·NPC·농작물 상태를 그대로 보존한다. 포장·운송·호송·재건축은 필요하지 않다.
3. 이주 비용, 이동 소요 시간, 기존의 48시간 재사용 대기시간을 없앤다. 지형·충돌·건축 금지 구역 검사만 통과하면 이동할 수 있다. 실제 전투 상태 중 이동만 제한하며 종료 후 별도의 30분 대기를 요구하지 않는다.
4. 제작·파견·재배·채굴의 진행률과 자원 잔량은 이어진다. 이동으로 완료 시간을 초기화하거나 보상을 중복 지급하지 않는다. 전력·냉각 연결은 함께 이전되어 유효한 설비가 자동으로 계속 가동된다.
5. 지형이 맞지 않으면 미리보기에서 배치를 조정한다. 확정 실패 시 기존 아지트와 물품은 그대로 유지한다. 성공 시 기존 위치의 거점을 제거하고 새 위치에 한 번만 생성한다.

아지트 이동은 생활 편의 기능이다. 일반 창고 물품을 무료로 함께 이동하는 것은 의도한 동작이며 약탈 대상이 아니다. 별도의 교역 임무를 시작해 생성한 교역 화물만 운송 콘텐츠로 취급한다. 교역 화물은 개인 창고에 넣을 수 없으며 캐릭터·운송 차량·선박에 남는다. 아지트 이동 시 플레이어·차량·교역 화물은 함께 순간이동하지 않는다. 활성 교역 계약이 있다는 이유만으로 아지트 자체의 이동을 막지는 않는다.

## 9. 생존·요리·혈액 연금술·하우징 성장

### 양 종족의 생활 구조

| 구분 | 인간 | 뱀파이어 |
| --- | --- | --- |
| 일상 원료 | 곡물·채소·고기·식수 | 원혈·약초·정제수·연금 재료 |
| 가공 | 주방에서 조리·보존식 제작 | 연금대에서 정제·배합·강화혈액 제작 |
| 기본 소모품 | 음식·물·요리 | 일반 혈액·강화혈액 |
| 생존 지표 | 포만도·수분 | 혈액량·혈액 안정도 |
| 고급 조합 | 오래 지속되는 포만감과 활동별 보조 효과 | 안정도 유지와 활동별 보조 효과 |
| 핵심 시설 | 주방·정수·식품 저장·냉장 | 연금대·혈액 정제·혈액 저장·냉각 |

### 인간: 음식·물·요리

채집·농사·사냥·NPC 거래로 식재료를 확보하고, 집수·정수로 식수를 마련한다. 일부 식재료는 바로 먹을 수 있지만 조리하면 안전성과 회복량·지속시간이 좋아진다. 물은 음용과 조리에 함께 쓰며 국물 요리는 포만도와 수분을 동시에 보충한다. 요리 숙련과 주방 확장은 생산량·보존성·레시피 선택을 늘린다.

| 요리 예시 | 재료 예시 | 생활 역할 |
| --- | --- | --- |
| 채소 수프 | 채소 + 식수 | 초반 포만도·수분 보충 |
| 고기 스튜 | 고기 + 작물 + 식수 | 긴 탐색을 위한 포만감과 체력 회복 보조 |
| 곡물 죽 | 곡물 + 식수 | 재배 기반의 저비용 상시 식사 |
| 보존식 | 고기/채소 + 소금·보존 재료 | 오래 보관하는 원정 비축품 |

### 뱀파이어: 혈액 확보·연금술·강화혈액

원혈 확보 → 오염 확인·필요 시 정제 → 약초·정제수 등 배합 → 강화혈액 제작 → 저장·휴대·섭취가 반복되는 생활 루프다. 혈액량은 활동과 일부 혈액 기술 사용으로 줄고, 혈액 안정도는 월드 시간 경과에 따라 서서히 낮아진다. 일반 혈액은 혈액량을 보충하는 응급·기초 수단이고, 강화혈액은 혈액량과 안정도를 함께 유지하는 정상 식사다. 일반 흡혈만으로 강화혈액 제작을 영구 대체하지 못하게 한다.

강화혈액은 장비 강화와 별개인 연금술 소모품이다. 레시피에 따라 채집·회복·야간 탐색 등 보조 효과가 달라진다. 기본 강화혈액은 시작 단계 연금대와 흔한 재료로 제작하며 고급 레시피는 선택이다. 안정도 부족은 경고 후 회복 효율·혈액 기술 효율이 점진적으로 낮아지는 방식으로 시작하고 즉시 사망·자동 좀비화를 일으키지 않는다. 좀비 감염도와 혈액 안정도는 독립 상태다.

| 강화혈액 예시 | 재료 예시 | 생활 역할 |
| --- | --- | --- |
| 안정화 혈액 | 정상 원혈 + 기본 약초 + 정제수 | 혈액량·안정도를 유지하는 기본 식사 |
| 활력 혈액 | 정상 원혈 + 활력 약초 | 채집·탐색 중 스태미나 회복 보조 |
| 재생 혈액 | 정제 혈액 + 회복 약초 | 휴식과 전투 후 회복 보조; 감염 치료 대체 불가 |
| 농축 혈액 | 원혈 여러 단위 + 보존 재료 | 휴대 슬롯 대비 공급량과 보존성 향상 |

일반 혈액은 동물 채혈·보관소 탐색·혈액상·파견의 복수 경로로 얻는다. 동물 채혈에는 회복 주기를 두고 선택적 사육 설비를 후속 확장으로 검토한다. 고급 혈액을 위해 특정 NPC를 반복 살해하도록 강제하지 않는다. 감염체 혈액은 의료 연구 또는 별도 정제 레시피에 사용하고 초반 필수 식재료로 두지 않는다.

### 지속 수급과 편의성

한 번 원료를 모아 여러 끼를 일괄 제작·저장하는 리듬을 목표로 한다. 표준 요리/강화혈액 한 묶음으로 일반 탐색 1회(활동 시간 20~40분)를 준비하는 것을 초기 기준으로 삼되 식사 빈도는 테스트한다. 생활용 혈액과 식량이 몇 분마다 바닥나 건축을 중단시키지 않도록 한다. 작업대는 연결된 개인 창고의 재료를 사용할 수 있고, 반복 제작·목표 재고·부족 알림을 지원한다.

원재료와 완성품에는 보존 기간이 있지만 냉장·냉각·보존식/농축 레시피로 늘린다. 부패와 소모는 월드가 진행될 때만 적용한다. 낮은 재고에는 상인의 기본 식사·기본 강화혈액으로 회복 경로를 제공하고, 편의성을 높인 생산 설비가 직접 채집을 점차 줄여주는 성장 보상으로 작동한다.

### 아지트 생활과 성장

식수 확보 → 작은 농장과 주방/연금대 → 저장·냉장 → 관개·일괄 생산 → 전문 생활 공간·장식·고급 시설 순으로 성장한다. 침실/관실·주방·연금실·창고·온실을 원하는 구성으로 배치한다. 가구·조명·바닥·벽 외형과 레시피는 탐색·제작·NPC 의뢰로 얻고 유료 해금은 없다. 전투 의뢰를 쉬면서 농사·요리·연금술·건축만 하는 플레이도 보상받아야 한다.

### 농사·식수와 시설

빗물은 모으는 것과 마실 수 있는 물로 만드는 과정을 분리한다. 집수 → 저장 → 여과/끓이기 → 소비가 기본이다. 오염 지역의 빗물은 추가 필터를 요구한다. 가뭄에도 우물·강물·교역소라는 대체 수단을 제공한다.

농사는 씨앗·토양·물·비료·빛을 사용하며 음식, 약초, 연료용 작물을 생산한다. 뱀파이어는 약초·혈액 제제용 작물과 종복 식량을 기른다. 초기에 간단한 수동 관리를 제공하고 이후 관개·저장·가공 시설로 자동화한다. 작물은 월드 시간이 진행되는 동안 성장한다. 월드 정지·일시정지 중에는 멈추며 완성 후 짧은 시간 안에 전부 소멸하는 구조는 피한다.

| 시설 | Lv.1 | Lv.2 | Lv.3 | Lv.4 |
| --- | --- | --- | --- | --- |
| 작업/가공 | 기본 도구 | 총기·방호 부품 | 정밀 합금·전자 제작 | 전문 장비 제작 |
| 의료/혈액 연구 | 응급 처치 | 중증 감염 치료 | 정화·혈화 대응 | 재료 효율·특수 제제 |
| 주방 | 기본 요리 | 일괄 조리·보존식 | 고급 조리·효율 개선 | 전문 레시피·생산 최적화 |
| 혈액 연금대 | 기본 안정화 혈액 | 일괄 배합·원혈 정제 | 고급 강화혈액·농축 | 전문 레시피·생산 최적화 |
| 식품/혈액 저장 | 기본 저장 | 냉장·냉각 | 저장량·보존성 향상 | 재고 관리·생산 연계 |
| 집수·정수 | 빗물통·끓이기 | 여과·저장 | 관개·오염 정화 | 생산 효율 향상 |
| 전력 | 소형 연료 발전 | 배터리·배전 | 고출력·냉각 | 고효율 전력망 |
| 동료/종복 숙소 | 1명·단기 임무 | 2명·중급 임무 | 3명·전문 임무 | 4명·동시 임무 최적화 |
| 통신/감시 | 지역 정보 | 파견 지원 | 위험 예측 | 물류·진영 지원 |
| 인간 차고/정비대 | 오토바이 보관·수리 | 험비 정비·적재 개선 | 상위 차량 연구 | 유지 효율·편의 개선 |
| 뱀파이어 변신 연구 | 박쥐 변신 해금 | 거대박쥐·운반구 | 상위 형태 연구 | 항속·유지 효율 개선 |
| 데이터 채굴 | 설치 불가 | 설치 불가 | 채굴 랙 1대·GPU 2개 | GPU 4개·효율 개선 |

각 시설은 재료·선행 연구·설치 공간·전력 조건을 만족해야 업그레이드된다. 상위 던전 재료는 일부 특수 전투 장비·선택적 산업 설비의 최종 강화에 사용한다. 기본 치료·진영 복귀·주방·연금대·농사·저장 등 핵심 생활 시설의 완성과 유지에는 필수가 아니며 생활 의뢰·일반 탐색·제작만으로 성장할 수 있다. 공용 설비는 양 진영에서 동등한 기능을 갖고, 외형과 일부 조합식으로 정체성을 구분한다.

예시: 전력 Lv.2 + 통신 Lv.2 → 정밀 작업 Lv.3 → 냉각 설비 → 채굴 Lv.3. 해금 조건은 UI에서 선행 시설과 부족 재료를 함께 표시한다.

## 10. 동료·종복 모집과 파견

인간은 구조·계약·평판으로 동료를 모집하고, 뱀파이어는 계약·의식·감염자 구제로 종복을 얻는다. 서로 다른 서사를 갖지만 기본 효율 상한은 동등하다. 일반 NPC를 무제한 납치해 생산량을 늘리는 구조는 배제한다.

NPC 능력은 전투, 수색, 운반, 의료로 구분한다. 임무 출발 전에 소요 시간·예상 보상 범위·부상 확률·필요 보급을 공개한다. ‘실패’는 보상 감소나 치료 시간으로 나타나며 기본 파견에서 영구 사망은 발생하지 않는다.

| 임무 | 시간 제안 | 요구 | 보상 | 위험 |
| --- | --- | --- | --- | --- |
| 인근 수색 | 1시간 | 기본 보급 | 목재·금속·일반 식량 | 낮은 부상 |
| 지역 회수 | 4시간 | 적합한 특성·장비 | 기계·의약·전자 부품 | 보급 손실·부상 |
| 전문 조사 | 8시간 | 통신·전문 NPC | 설계 단서·희귀 자원 소량 | 치료 필요·보상 감소 |

표의 시간은 게임 내 시간이다. 파견은 플레이어가 다른 활동을 하는 동안 진행되고, 월드 종료·일시정지 중에는 멈춘다. 수면·시간 건너뛰기에는 경과 시간을 함께 정산한다. 완료 보상은 수령 전까지 보호한다. NPC는 주간 귀속 핵심 재료와 GPU 완제품을 직접 공급하지 않지만 강화 주문서는 일반 보상으로 제공한다. 파견은 UI 기반 시간제 임무로 구현하고, 월드의 진영 교역대는 별도 AI 콘텐츠로 구분한다.

동행 NPC는 초기 1명까지 데리고 갈 수 있다. 동행/대기/귀환, 공격/소극 대응 명령을 제공하며 같은 NPC를 파견과 동행에 동시에 배정할 수 없다. 모든 필수 던전은 동행 없이도 공략 가능해야 한다.

## 11. 주간 퀘스트·던전

### 주간 퀘스트

전투, 생활, 운송, 진영 기여 중 3개 목표를 골라 주간 주요 보상을 완료할 수 있다. 특정 PvP 승리만 강제하지 않는다. 예: 중증 감염 치료 지원, 정수 물품 납품, 변이체 조사, 화물 운송, 전초기지 수리.

### 주간 제한의 대상

던전 입장 자체가 아니라 ‘상위 보상 획득’을 월드 내 캐릭터별 게임 내 7일 주기당 3회로 제한하는 안을 제안한다. 싱글에서 현실 일주일을 기다리지 않도록 월드 달력을 사용하고, 퀘스트·던전·상인 한도를 같은 주기에 맞춘다. 수면으로 주기가 바뀌어도 보스 공략은 필요하며 미수령 횟수는 누적되지 않는다. 보스 보상 수령과 횟수 차감을 함께 저장한다. 전멸·입장·중도 종료는 차감하지 않는다. 향후 멀티도 개인 PC 서버의 같은 월드 달력을 따른다.

| 보상 | 귀속/거래 | 위험 | 제한 |
| --- | --- | --- | --- |
| 연구 인증·핵심 해금 재료 | 월드 내 캐릭터 귀속 | 보스 정산 즉시 보호 | 주간 3회 |
| 상급 합금·전자 부품 | 거래 가능 | 출구부터 반출 화물 | 주간 상위 상자에서 획득 |
| 일반 재료·통화 | 거래 가능 | 일반 화물 규칙 | 재입장 시 소량 획득 |

귀속 핵심과 거래 자원을 분리해 진척 전체가 한 번의 출구 매복으로 사라지는 것을 방지하고, 여전히 좋은 물품의 반출 경쟁을 만든다. 핵심 재료 요구량과 주간 지급량을 함께 계산해 필수 시설 하나에 지나치게 긴 고정 대기를 만들지 않는다.

던전은 1인 기준으로 설계하고 NPC 동행은 선택이다. 동시 발판·복수 인원 강제 역할 같은 기믹은 배제한다. 접근과 귀환의 위험은 감염체·적대 순찰·NPC 매복이 담당한다. 여러 출구와 우회로를 제공한다. 향후 멀티는 입장 플레이어 수에 따라 적 수·체력·공격 빈도를 조절하고, 각자의 상위 보상 횟수를 따로 정산한다. 3회 소진 후에도 일반 보상으로 반복 공략할 수 있다.

초기 던전 3종 콘셉트: 폐쇄 병원(치료·변이 샘플), 지하 혈액 저장고(혈화·안정화), 통신 연구소(전자·산업 설비). MVP에는 한 종만 구현한다.

## 12. 약탈·범죄·해적질

싱글의 주요 약탈 대상은 적대 진영 NPC 교역대·보급 창고이며, NPC도 플레이어 교역 화물을 습격한다. 우호 교역대 호송과 적대 교역대 습격을 선택할 수 있다. 해상 확장에서는 NPC 운송선과 해적 NPC가 같은 역할을 담당한다.

운송은 생산지에서 구매/제작한 교역품을 수요가 있는 거점으로 가져가 판매하는 활동이다. 교역 화물은 전용 휴대 슬롯 또는 차량·선박·거대박쥐 운반구 슬롯을 차지하며 개인 창고에는 보관할 수 없다. 교역 화물 자체의 빠른 이동만 제한하고, 개인 아지트와 일반 창고 물품의 즉시 이동은 허용한다. 수익은 거리뿐 아니라 목적지 수요와 위험도를 반영한다.

적대 진영의 분쟁 지역 화물 공격은 전쟁 행위다. 동진영 공격은 기본 불가하되 플레이어가 ‘무법 행동’을 명시적으로 켜면 가능하다. 켜는 즉시 전투 중 변경할 수 없는 범죄 상태가 적용되고 양 진영의 공격 대상이 된다. 무법자는 제3진영이 아니라 원래 종족의 범죄 상태다.

범죄 중에는 보호 정착지 진입, 정상 교역소, 진영 창고 접근이 제한된다. 지정 암시장 판매와 평판 회복 임무를 이용한다. 단순 로그아웃으로 범죄를 해제하지 않는다. 현상금은 지정 NPC와 임무 식별자를 기준으로 지급하고 동일 목표 반복 지급을 막는다. 향후 PvP 현상금은 소규모 친구 간 반복 처치로 무한 생성되지 않게 별도 제한한다.

탈취 화물은 장물로 표시되며 암시장 또는 위험한 세탁 운송을 거쳐야 판매 가능하다. 장물의 원산지·최초 소유자·이동 로그를 유지한다. 초기에 육상 약탈을 검증한 뒤 항만·소형 선박·승선 전투·해상 운송을 추가해 해적질을 완성한다.

## 13. 거점 방어와 NPC 전초기지

1인 플레이에서는 접속자 없음·일시정지 시 월드가 정지하므로 오프라인 습격·유지비 체납·장기 미접속 철거가 없다. 개인 아지트 핵심 구조와 창고는 보호한다. 생존 긴장감은 원정·화물 습격·진영 전초기지 공격에서 만든다. 향후 개인 거점 방어 이벤트를 추가할 경우 사전 경고와 선택 난이도로 제공한다.

NPC 전초기지에는 경비·방어 장치·보급 창고가 있다. 플레이어는 진영 의뢰를 수락해 공격하거나 우호 NPC와 방어한다. 소규모 전초기지는 1인으로 해결 가능하며 더 큰 목표는 NPC 지원을 제공한다. 주말 접속이나 고정 현실 시간 공성을 요구하지 않는다. 점령은 주변 순찰·상인 공급·의뢰를 변화시키며 전투력의 영구 누적 보너스는 최소화한다.

향후 멀티에서도 개인 창고는 기본 보호하고 공유 건축 권한은 월드 관리자가 지정한다. 다른 플레이어의 개인 아지트 파괴는 기본 비활성화한다. 진영 PvP는 월드 관리자가 선택한 분쟁 지역 규칙 안에서만 허용한다.

## 14. 경제와 GPU 채굴

주요 화폐는 크레딧이다. 의뢰·NPC 납품·화물 교역·채굴 토큰 판매로 유입되고, 치료·수리·연료·탄약·파견·거래 수수료로 소모된다. 유저 거래는 기존 화폐의 이동이며 신규 화폐 발행과 구분해 집계한다.

GPU는 연구소·데이터 시설의 희귀 물리 전리품으로 배치한다. 채굴장은 게임 속 데이터 복구 연산으로 ‘암호 토큰’을 생산하고 NPC 상인에게 판매한다. 실제 암호화폐나 현금 환전과 연결하지 않는다.

### 채굴 운영

- GPU 슬롯, 전력, 냉각, 연료, 수리 부품을 모두 요구한다.
- 월드 시간이 흐르고 자원이 남아 있으면 생산하며 보관함이 차면 정지한다. 월드 정지·일시정지 중에는 생산하지 않는다. 생산 보관 상한 게임 내 24시간 제안.
- GPU 증설은 수익을 늘리되 한계효율은 감소시킨다. 월드 내 플레이어별 가동 랙 상한을 둔다.
- 전력 부족 시 의료 냉장·생존 시설을 우선하고 채굴을 자동 중지하도록 우선순위 UI 제공.
- NPC 토큰 매입은 월드 내 캐릭터별 게임 내 주간 한도와 공개 가격표를 사용한다. 공급에 따른 가격 변화는 거래 화면에서 미리 표시한다.
- GPU 완제품은 거래 가능하나 기본 NPC 파견 보상에서는 제외한다.

밸런스 예시(아래 하루·일은 게임 내 날짜 기준): GPU 2개로 하루 토큰 4개 × 500크레딧 = 총매출 2,000. 하루 연료·냉각·수리 1,200이면 순이익 800. 초기 투자 12,000이면 단순 회수기간은 15일이다. 이는 전력 중단·한도·시세·기회비용을 제외한 테스트 산식이며 확정 가격이 아니다. 수동 원정이 여전히 더 높은 기대 수익을 가져야 한다.

테스트 지표: 플레이 시간 대비 수입·지출, 거점 성장 단계별 GPU 보유량, 캐릭터당 토큰 매출, 치료비를 회복하는 원정 횟수, 교역 성공률. 자동 생산 수익이 지출 없이 계속 누적되면 가격만 올리기보다 생산량·슬롯 상한·매입 한도를 함께 조정한다.

## 15. 화면·카메라·UI·접근성

### 2D 쿼터뷰 표현

좀보이드에서 사용자가 원하는 사선 내려다보기 경험을 기준으로, 2D 아이소메트릭 타일과 캐릭터 스프라이트를 사용하는 아트 방향을 설정한다. 이는 본 게임의 제작 방향이며 참고 게임의 내부 렌더링 구현을 단정하는 설명이 아니다. 픽셀 아트 여부와 해상도는 후속 아트 결정 사항이다.

- 카메라: 고정 사선 각도, 캐릭터 추적, 제한된 확대·축소. 자유 회전은 기본 범위에서 제외한다.
- 실내: 진입 시 지붕과 상층을 숨기고 캐릭터를 가리는 전면 벽은 투명하게 처리한다. 표현상 투명해진 벽도 충돌·총격 차폐·시야 차단 기능은 유지한다.
- 시야: 카메라 화면에 들어온 위치와 캐릭터가 실제로 볼 수 있는 위치를 구분한다. 벽 뒤·시야 밖 적은 표시하지 않으며, 소리는 방향 단서만 제공한다. 뱀파이어 추적 능력도 허용된 단서만 제공한다.
- 층: 현재 층 중심으로 표시하고 계단 이동 시 전환한다. 서로 다른 층의 캐릭터·시설·상호작용 대상이 겹쳐 선택되지 않도록 한다.
- 전투 가독성: 진영 실루엣, 타격 방향, 범위 공격, 감염 전조를 작은 캐릭터 크기에서도 식별 가능하게 만든다.
- 향후 PvP 공정성: 화면 비율과 줌에 따른 최대 정보 범위를 제한하고, 가림 처리로 적 위치가 새지 않도록 검증한다.
- 아지트 이동: 동일한 그리드 위에서 전체 아지트 배치를 미리보고 즉시 확정한다. 시설·창고·진행 상태의 통째 이동 규칙을 유지한다.

### 상태와 정보 UI

HUD: 체력·스태미나, 인간의 포만도·수분 또는 뱀파이어의 혈액량·안정도, 요리/강화혈액 효과·남은 시간, 감염 단계·혈화/정화 타이머·현재 구역의 사망 손실을 표시. 두 감염 상태는 색뿐 아니라 아이콘·문구로 구분한다.

지도: 진영 경계, 위험 지역, 거래소, 다중 출구, 깃발 금지 구역. 운송 시 도착 예상 보상과 경로 위험을 보여주되 적의 정확한 실시간 위치는 제공하지 않는다.

시설 화면: 현재 레벨, 다음 효과, 부족 재료, 선행 설비, 전력 수지. 파견 화면: 시간과 확률을 출발 전에 고지. 적대 전환·무법 모드·고위험 진입에는 결과를 명확히 안내한다. 손실 규칙을 긴 약관 대신 현장 UI에서 확인할 수 있어야 한다.

## 16. 웹 접속·개인 PC 서버·저장 구조

### 확정 방향과 기본 구성

설치 프로그램 없이 링크를 열어 브라우저에서 플레이한다. 게임 실행 서버와 영속 저장소는 제작자의 개인 PC에 둔다. 싱글 우선은 ‘다른 플레이어 없이 콘텐츠가 완결됨’을 의미하며 오프라인 브라우저 게임을 뜻하지 않는다. 최초 구현부터 브라우저와 개인 PC 서버 사이의 접속·저장 경로가 필요하다.

기본 구성은 브라우저 클라이언트 → HTTPS/WSS 공개 접속 주소 → 개인 PC의 웹·게임 서비스 → 개인 PC 저장소다. 브라우저는 화면·소리·입력·표시 보간을 담당하고, 서버는 월드 시간·NPC·전투 결과·감염·강화·인벤토리·건축·생산을 확정한다. 게임 데이터는 브라우저 저장소를 지워도 유지되어야 한다.

### 링크 접속과 개인 PC 운영

- 사용자 흐름: 링크 열기 → 필요한 게임 리소스 로딩 → 닉네임/기존 캐릭터 확인 → 입장. 별도 게임 설치와 복잡한 가입을 기본 요구로 두지 않는다.
- 일반 접속 URL과 캐릭터 소유권은 구분한다. 최초 접속 때 서버가 플레이어 ID를 발급하고 브라우저에 접속 세션을 저장한다. 다른 기기나 브라우저 데이터 삭제 후 복귀할 수 있도록 별도의 복구 코드 또는 관리자의 복구 기능을 제공한다. 공용 링크만 알면 다른 캐릭터를 사용할 수 있게 만들지 않는다.
- 외부 접속에는 PC의 로컬 주소만으로 부족하므로 외부에서 도달 가능한 공개 주소가 필요하다. 실제 네트워크 조건을 확인한 뒤 포트 개방·주소 연결 또는 터널 방식 중 하나를 선택한다. 특정 서비스나 무료 이용 한도는 아직 확정하지 않는다.
- 공개 접속은 HTTPS와 WSS를 사용하고, 게임 서비스에 필요한 경로만 노출한다. 저장소·운영체제 원격 제어·관리 기능은 일반 게임 링크에서 접근할 수 없게 한다.
- 개인 PC가 켜져 있고 게임 서버와 인터넷 연결이 동작하는 동안 외부 접속할 수 있다. PC 종료·절전·재부팅·인터넷 중단 동안은 접속되지 않는다. 브라우저를 닫는 것과 서버 프로그램을 종료하는 것은 별개다.
- PC 전원 복구 후 마지막 정상 저장에서 월드를 재개한다. 서버가 꺼져 있던 현실 시간을 감염·부패·생산에 추가 반영하지 않는다.
- 게임 내 과금은 없으며 운영 비용은 별개다. 개인 PC의 전력·인터넷, 선택 시 도메인·연결 서비스 등의 비용이 발생할 수 있다. 무료 외부 서비스의 상시 제공을 전제로 설계하지 않는다.

### 월드 시간·일시정지·접속 끊김

월드에 접속자가 없으면 시뮬레이션을 정지하는 것을 기본안으로 한다. 서버 프로세스는 켜둔 채 다음 접속을 기다릴 수 있다. 1명만 접속했을 때 일시정지는 서버 월드도 멈춘다. 향후 멀티에서는 전원 동의로 일시정지·수면·시간 건너뛰기를 처리한다. 혼자 메뉴를 연 것만으로 다른 사람의 월드를 정지시키지 않는다.

일시정지·빈 월드·서버 종료 중에는 농사·부패·파견·채굴·감염이 진행하지 않는다. 다른 사람이 접속 중이면 월드의 농사·생산·달력은 계속 진행하되 로그아웃한 캐릭터의 허기·혈액량·감염은 보호한다. 아지트와 개인 창고는 기존 보호 규칙을 따른다. 접속 복귀 시 이미 흐른 시간을 다시 중복 정산하지 않는다.

감염·혈화의 활동 시간은 월드 시간 배율로 환산한다. 수면·시간 건너뛰기로 감염 임계점에 도달하면 건너뛰기를 중단하고 대응하게 한다. 연결이 끊기면 클라이언트는 서버 확인 없이 행동·보상·제작을 확정하지 않는다. 1인 플레이에서는 즉시 월드를 멈추고 복귀를 기다린다. 향후 멀티의 전투 중 이탈은 짧은 재접속 유예를 검증한 뒤 안전 로그아웃으로 전환하고, 보호가 시작된 뒤에는 캐릭터 생존 수치를 소모하지 않는다.

### 영속 저장·백업

NPC, 시설, 차량 상태·적재품·변신 해금·운반구, 인벤토리, 음식·혈액 재고와 보존 상태, 종족 전환 이력·복귀 경로, 감염, 강화 단계·실패 누적, 파견, 채굴, 달력·주간 보상을 개인 PC의 저장소에 기록한다. 보상 수령·강화·아지트 이동은 재료 차감과 결과를 하나의 거래로 저장해 중복·유실을 막는다. 중요한 거래 직후 저장과 주기 자동 저장, 정상 종료 저장을 함께 적용한다.

저장 형식에 버전을 두고 업데이트 시 기존 아지트와 진행을 이전한다. 관리자는 월드 백업을 내보내고 복구할 수 있어야 한다. 개인 PC 고장에도 복구할 수 있도록 별도 디스크나 외부 위치에 백업 사본을 보관하는 운영 절차를 둔다. 복구는 월드 단위이며 향후 멀티 게스트가 다른 사람의 진행을 임의로 되돌릴 수 없다. 브라우저 새로고침·재접속·서버 재시작 후 같은 캐릭터와 아지트로 돌아오는 것을 필수 검증한다.

### 향후 소규모 멀티

초기에는 서버당 1인 플레이를 완성하고 이후 동시 2~4인을 제안한다. 정확한 최대 인원은 개인 PC 성능과 업로드 회선, NPC·건축 부하를 측정해 결정한다. 서버 소유자가 브라우저에서 플레이하지 않아도 서버 프로그램이 실행 중이면 다른 사용자가 접속할 수 있다.

캐릭터 진행은 서버 월드와 플레이어 ID에 귀속한다. 다른 월드의 아이템 반입은 기본 금지한다. 협동은 기본값, 진영 PvP는 월드 관리자가 선택하는 모드다. 혼합 종족 파티를 허용하되 NPC 진영 평판과 정착지 접근은 개인별이다. 글로벌 거래소·대규모 길드전·다수 서버 분산은 범위에서 제외한다.

### 기술 선택과 브라우저 성능

특정 엔진·프레임워크는 미확정이다. 브라우저 2D 렌더링과 개인 PC의 권위형 게임 서버를 분리하고, 웹 배포·실시간 통신·저장 구현을 먼저 검증한다. 전투·건축·AI 로직이 화면 프레임 속도와 독립적으로 동작하도록 한다.

맵은 구역 단위로 전송·로딩하고, 스프라이트 리소스를 묶어 초기 다운로드를 줄인다. 서버는 플레이어 근처의 NPC와 변경된 상태를 우선 전송하고 먼 구역은 간략 계산한다. 초기 지원은 키보드·마우스를 사용하는 데스크톱 브라우저로 제안하며 모바일 터치 조작은 별도 확장 범위다. 2D라는 이유만으로 대량 NPC·무제한 건축이 가볍다고 가정하지 않는다.

## 17. 콘텐츠 범위와 개발 순서

### A. 싱글 핵심 프로토타입

브라우저 1인 클라이언트와 개인 PC 서버, URL 접속·통신·서버 저장, 작은 2D 쿼터뷰 맵, 실내 가림·시야, 인간/뱀파이어 선택, 양 진영 전투 NPC 각 1종과 상인·의뢰 NPC, 좀비 2종, 감염·치료·종족 전환, 즉시 이동 아지트, 기본 주방·연금대·요리·강화혈액 수급, 제작·강화 +3, 종족 복귀와 아지트 보존, 저장/불러오기를 검증한다. 다른 플레이어 없이 30분 생존·파밍·성장 루프가 성립하는지 확인한다.

### B. 싱글 MVP / 수직 단면

- 하나의 월드 구역과 양 진영 정착지·분쟁 지역.
- 양 진영의 상인·치료자·의뢰 담당자·경비·순찰대.
- 무기 역할 각 2개, 좀비 3종 + 감염 뱀파이어 1종, 낮·밤.
- 인간 오토바이와 뱀파이어 박쥐 변신, 기본 소모·적재·착지·저장 검증.
- 즉시 이동 아지트와 시설 초기 단계, 식수·농사·전력·가구 배치.
- 인간 요리와 뱀파이어 강화혈액 각각 기본 레시피 3종, 혈액 수급·정제·냉각, 일괄 제작·저장.
- 종족 변화 후 기한 없는 복귀 경로와 아지트·시설·재고 보존.
- NPC 동행 1명, 파견 3종, 1인 던전 1종과 게임 내 주간 보상.
- NPC 교역대 1종과 호송·약탈, 소규모 전초기지 공격·방어.
- 강화 +10과 주문서 수급·실패 누적·계승, GPU 채굴 1단계.

### C. 싱글 콘텐츠 확장

험비·거대박쥐와 상위 이동 계열, 생활 레시피·가구·건축 외형·생산 편의 기능 확장을 우선하고, 이후 다지역 월드·추가 던전·시설 Lv.4·심화 진영 의뢰·해상 운송·NPC 운송선 약탈을 추가한다. 거대 길드전과 글로벌 시장은 범위에서 제외한다.

### D. 소규모 멀티 확장

기존 개인 PC 서버에 동시 접속·상태 동기화·개인별 저장을 확장하고, 2~4인 협동, 인원별 던전 조정, 공유 권한, 선택형 진영 PvP를 추가한다. 정확한 최대 인원과 출시 시점은 싱글 안정화 후 결정한다.

엔진·기술 스택은 웹 배포, 2D 타일맵·정렬·가림, 서버 AI·저장 안정성과 팀 경험을 기준으로 결정한다. 첫 프로토타입부터 개인 PC 서버와 브라우저를 연결하되 대규모 서버 인프라는 구현하지 않는다.

## 19. 아직 확정해야 할 결정

1. 생존·하우징 중심은 확정. 생활 소모 속도, 제작 편의와 NPC 전투 콘텐츠 비중의 세부 수치.
2. 종족 복귀 가능·아지트 보존은 확정. 치료 과정의 난도와 필요한 활동량.
3. 웹 플랫폼·개인 PC 서버는 확정. 픽셀 아트 여부, 초기 지원 브라우저·기기와 조작 세부.
4. 개인 PC 사양·운영체제·인터넷 업로드 환경, 외부 접속 방식, 기술 스택·개발 일정.
5. 상위 차량·상위 변신의 이름·외형, 거대박쥐 동료 탑승과 운반 한도. 향후 멀티 최대 인원(2~4인 제안)과 협동/PvP 세부 설정.
6. 강화 확률·단계별 수치와 게임 내 주간 주기: 아래 강화 및 시간 규칙은 테스트용 제안.
7. 시즌 없음·과금 없음은 확정 사항이며 수익화 기능을 개발 범위에 넣지 않는다.

다음 상세 기획 우선순위는 음식·혈액 수급 수지, 요리·강화혈액 레시피, 하우징·생활 시설 성장, 종족 복귀·저장 보존, NPC 진영 AI와 장비 강화 수지표다.
