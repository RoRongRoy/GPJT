# 개발 순서와 완료 조건

## P0 · 현재 패키지

생활 수직 단면, 서버 저장, 종족 전환·거점 유지, 강화, 이동 형태 체험. 상태는 STATUS 참조.

## P1 · 생존 하우징을 게임으로

- P1-01 자유 배치: 바닥·벽·문·가구. 비용·충돌·진입 통로 검증, 즉시 이주 후 전체 보존.
- P1-02 재배·집수: 파종→성장→수확, 빗물→여과. 빈 월드 정지 검증.
- P1-03 생활 생산: 주방/연금대 일괄 제작, 냉장/냉각, 부패, 연결 창고.
- P1-04 인벤토리 분리: 휴대·창고·적재 한도. 이전 스키마 migration 제공.
- P1-05 시설 효과: 각 단계의 레시피·효율·저장량이 실제로 달라질 것.
- P1-06 종족 생존: 채혈·혈액 거래·기초 강화혈액 비축, 원료가 막혀도 복귀 가능.
- 완료: 각 종족 30분 생활·건축 플레이가 전투 강제 없이 유지됨.

## P2 · 살아 있는 월드

- 진영 NPC 상점·의뢰·평판·순찰, 특성 있는 동료/종복 모집.
- 강화좀비·돌연변이, 명확한 물림 전조, 혈화·정화 타이머, 치료·복귀.
- 1인 던전과 주간 보상, 생활 필수 재료의 던전 독점 금지.
- 차량 객체·연료·수리·화물, 비행 통과/착지 속성·거대박쥐 운반구.
- 완료: NPC 없이 막히는 복구 없음, 시체·화물·거점 이주 거래 정합성 검증.

## P3 · 장기 성장

GPU·전력·냉각·채굴 수지, NPC 교역·호송·약탈, 선택적 해상 운송, 장비별 강화·계승, 고급 주거 장식. 상위 이동 형태 이름은 사용자 결정 후 반영.

## P4 · 외부 접속과 소규모 멀티

공개 접속 운영 준비는 P0부터 병행할 수 있으나 멀티 기능은 이후 구현합니다. 생산용 HTTP 계층, HTTPS/WSS, 사용자별 캐릭터·권한·복구, 2~4인 제안 규모의 동기화, 합의 일시정지, 협동/PvP 선택. 정확한 인원은 실제 PC/회선 측정 후 확정.

## 공통 완료 정의

해당 요구 ID 연결, 실패·복구 경로, 저장 migration, 자동 테스트, 브라우저 확인, STATUS/API 변경 반영. 기획 전체 구현 완료로 표시하려면 모든 관련 체크를 통과해야 합니다. 출시 날짜는 인력과 PC 환경 확인 전 약속하지 않습니다.
