# 저장·복구

## 자동 저장

`data/world.sqlite3`: 전체 월드. SQLite WAL은 실행 중 별도 파일을 만들 수 있습니다. `data/access.key`: 접근 키. 두 항목 모두 레포 제외.

명령 성공 직후 commit, tick은 2초 주기 저장, Ctrl+C 시 최종 저장. 프로세스를 강제 종료하면 마지막 2초의 비명령 변화가 사라질 수 있습니다. 새로고침은 캐릭터를 새로 만들지 않습니다.

## 일관된 백업

레포 루트에서:

```sh
python tools/backup.py
```

SQLite backup API로 실행 중에도 일관된 복사본을 만듭니다. 결과 `backups/world-날짜.sqlite3`. 파일을 별도 디스크로 복사해 PC 고장에 대비하세요. 접근 키는 별도로 비공개 보관합니다. 백업 도구는 업로드·공유하지 않습니다.

## 복원

1. 서버를 Ctrl+C로 정상 종료합니다.
2. 현재 `data` 폴더 전체를 별도 위치에 보관합니다.
3. 빈 새 저장 디렉터리를 만들고 선택한 백업을 `world.sqlite3`로 복사합니다.
4. `python -m server.main --data 복원디렉터리/world.sqlite3`로 실행합니다.
5. 새 키가 생성되면 콘솔 링크로 접속하고 아지트·인벤토리·종족을 확인합니다.

기존 WAL 파일 위에 다른 DB를 덮어쓰지 마세요. 새 디렉터리를 사용하면 충돌을 피할 수 있습니다. `version`이 호환되지 않으면 서버가 중지하며, 데이터 삭제를 복구 방법으로 안내하지 않습니다.

## 초기화

시즌 초기화 기능은 없습니다. 개발용 새 월드는 `--data`에 새 경로를 주면 만들 수 있습니다. 이전 저장을 지우지 않습니다.
