# 현재 구현 상태 · P0

전체 GDD v0.7과 실행 코드 사이의 차이를 공개하는 문서입니다. P0는 게임 완성도가 아니라 생활 루프·저장 구조를 검증하는 단계입니다.

## 0.5.1 조작·렌더링

스프라이트·투영 지형·장식 배치·화면 효과를 캐시하고 화면 밖 오브젝트를 제외합니다. 미니맵은 최대 10Hz로 갱신합니다. 이동 명령 한 건이 응답 대기 중일 때 해당 한 걸음만 시각적으로 예측하며 실제 좌표와 자원은 서버 결과로 확정합니다. 거절·접속 오류 시 예측을 해제하고 복구합니다. 이동 요청을 누적하지 않으므로 높은 통신 지연에서 연속 이동 속도가 느려질 수 있습니다. [측정 방법과 결과](PERFORMANCE.md)를 참고하세요.

## 인게임 아트워크

프로젝트용으로 새로 생성한 고딕 도시 배경과 인간·뱀파이어 초상을 종족 선택·생존·아지트 메뉴에 사용합니다. 필드는 새로 생성한 투명 PNG 피난처·폐허·소나무·고사목, 우물·폐트럭·보급소·가스등·4종 시설, 인간·뱀파이어·마른/육중한 감염체의 보행 시트로 표시합니다. 석재와 흙 텍스처는 월드에 고정되며 정적 지형을 캐시합니다. 4방향×4보행 프레임을 사용하고 인간·마른 감염체의 뒤쪽 한 방향은 좌우 반전으로 보완합니다. 몬스터 외형 2종은 능력치 차이를 추가하지 않습니다. 탑승 형태와 일부 식물·효과는 기존 벡터 표현을 유지합니다. 안개와 건축물은 시각 표현이며 신규 날씨·던전·충돌 기능을 의미하지 않습니다. [아트 방향](ART_DIRECTION.md)과 [자산 목록](../ASSETS.md)에 출처와 범위를 기록합니다.

## 상황별 UI

지도와 간단한 체력·생활 지표를 기본 표시합니다. 생존·보관품·수첩·이동 버튼으로 한 분류씩 열며, 모바일에서는 하단 패널로 표시합니다. 보관품은 재료·소모품·강화, 수첩은 첫 생존·의뢰·기록으로 나뉩니다.

아지트 메뉴는 서버의 이용 반경 2.8 안에서만 표시됩니다. 제작·시설·연구·파견을 선택하고, 제작 안에서는 요리·연금·치료 중 한 조합식과 재료/시설 조건을 표시합니다. 이탈·이동·접속 해제 때 관련 메뉴를 닫으며, 원거리 제작 등은 서버에서도 거절합니다. 즉시 이주·구조·이동 형태 사용은 이동 메뉴에서 유지합니다. 메뉴를 열어도 자동 일시정지하지 않습니다.

## 탐험 화면

64×64 맵에 외곽·소나무숲·저지대·공업지대 4개 지역, 자원/NPC 29곳, 일반 감염체 11개체가 있습니다. 기존 시작 위치와 자원 ID는 유지합니다. 캐릭터를 따라가는 카메라와 65~160% 줌, 전체 미니맵 클릭 이동, 넓게 보기를 제공합니다.

WASD/방향키는 화면 방향으로 이동합니다. 클릭/탭 목적지 이동·도착 후 1회 채집/공격, 아지트 귀환 이동, Esc 취소, 작은 화면의 방향패드를 지원합니다. 나무·물가·폐허는 장식이며 지형 충돌·길찾기는 없습니다. 미니맵에 탐험 전 지역도 표시됩니다.

필드 그래픽은 원본 PNG 스프라이트와 Canvas 합성, 메뉴는 생성 일러스트와 CSS를 사용합니다. 이미지 로딩 실패 시 기존 도형 렌더러로 대체합니다. 관리는 분류형 메뉴로 열고, 첫 생존 안내를 수첩에 유지합니다. 기존 저장은 초기화하지 않고 누락된 새 지역 감염체만 추가합니다.

## 실제 동작

서버가 이동 범위·속도·재료·시설 거리·강화·공격을 판정합니다. 사람/뱀파이어 선택, 자원 채집 6종, NPC 2명, 5회 채집 반복 의뢰, 수프·혈액·약초·안정화 혈액·치료제, 시설 4종 건설, 안전 지점으로 아지트 즉시 이동, 파견 보상, 물림 감염·치료·긴급 복구, 의료실의 양방향 종족 변환, 무기 강화 +10을 사용할 수 있습니다.

SQLite로 저장하고 재시작 시 복구합니다. 1개 브라우저 세션에 조작 권한을 임대합니다. 닫힘/숨김 후 약 1.2초 안에 월드 시간 정지, 다른 탭은 마지막 활동 4초 후 권한 획득 가능. 정지 버튼은 서버 시간을 멈춥니다.

## 아직 없음

멀티/PvP, 실제 원거리 총격, 강화좀비·돌연변이, 던전·주간 제한, GPU 채굴, 연료·전력, 교역·약탈·해전, 소리·음악, 8방향·공격·피격·사망 전용 애니메이션 세트, 실내 가림·층·충돌 지형, 모바일 전용 조이스틱. 공개 인터넷 상용 운영 수준의 인증·부하 제어·보안 강화도 미완성입니다.

## P0 종료 조건

양 종족 각각 자원 확보→기초 소모품 제작·섭취→시설 성장, 아지트 이동 및 종족 복귀 후 보존, 브라우저 재접속과 서버 재시작 후 저장 복원을 검증합니다. 다음 기능은 ROADMAP 순서로 추가합니다.
