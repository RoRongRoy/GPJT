GitHub Actions에서 서버/클라이언트 검사와 실제 브라우저 신규 접속·계정 불러오기·스킬 HUD 회귀 검사를 실행합니다. 모두 성공한 main 커밋만 Linux의 bloodfall 라벨 실행기에 배포하도록 구성했습니다. 서버 연결 및 저장소 변수 활성화는 아직 필요합니다. Docker 저장 볼륨·업데이트 전 SQLite 백업·건강 검사·실패 시 이전 이미지 복귀 시도를 제공합니다. [연결 절차와 무료 운영 조건](AUTOMATION.md).

## 필드 HUD 및 빈 스킬 슬롯

필드를 전체 화면으로 표시하고 좌상단 초상·HP/MP, 좌측 생존 목표·활동 기록, 우상단 직접 접근 메뉴·미니맵, 우측 원형 전투 버튼, 하단 중앙 아이콘 스킬 바와 우측 치료제/식수 바로 사용, 바닥 경험치 막대로 구성합니다. 기존 게임 아트와 서버 규칙을 유지하며 참고 이미지의 화면 배치를 반영합니다. 모바일 세로·가로 화면에서도 메뉴와 조작 영역을 분리합니다.

스킬창(K)의 1~6번 사각 슬롯에 습득한 스킬을 클릭/탭 또는 PC 드래그로 배치합니다. 처음 설정은 모두 빈칸이며 새 스킬을 해금해도 자동 등록하지 않습니다. 슬롯 선택 후 `선택 슬롯 해제`로 비울 수 있고, 필드의 빈칸을 누르면 해당 슬롯을 설정합니다. 이미 등록된 스킬끼리는 교환하며 빈칸으로 옮기면 원래 칸이 비워집니다. 숫자 1~6으로 시전하고 빈칸·메뉴 열림 상태에서는 숫자로 시전하지 않습니다.

배치와 빈칸은 브라우저 localStorage v4에 보관합니다(계정 서버 동기화 없음). 이전 버전 배치의 습득 스킬은 유지하고 중복·잘못된 ID·미습득 스킬은 빈칸으로 정리합니다. 새 스킬을 자동 보충하지 않습니다. 필드에는 등록 스킬의 직접 만든 SVG 아이콘과 재사용 대기 가림 효과만 표시합니다. 스킬창에서 이름·효과를 확인하며 스크린리더 이름/마우스 설명을 제공합니다. 상태 갱신 중에도 카드와 포커스가 유지됩니다. 검증: `node tests/hotbar_browser.cjs` (PC·모바일 세로·가로, 빈칸·등록·해제·재접속·키 시전·HUD 영역).

## 현재 이동·걷기/달리기

키보드·터치 방향패드는 서버에 최신 방향을 약 100ms마다 전달하고, 서버는 경과 시간으로 이동량을 계산합니다. 기본 속도 6칸/초, 달리기 9.9칸/초이며 대각선 속도를 정규화합니다. 탑승 질주는 해당 형태 속도의 1.25배입니다. 화면은 입력에 즉시 반응한 뒤 서버 좌표로 보정합니다. 입력 유실 시 마지막 입력은 0.4초 뒤 만료되며 누른 키 상태는 저장하지 않습니다. 클릭 목적지·자동사냥에는 단일 보폭 명령을 유지합니다.

최신 종족/성별 스프라이트의 크기·기준점과 직업 외형을 유지하면서 보행 프레임·발자국·몸의 상하 움직임을 실제 이동 거리로 동기화합니다. Shift/버튼으로 걷기와 달리기를 전환하고 키를 놓으면 정지 자세로 돌아옵니다. 순간이동·정지 후 위치 보정·일시정지 때 발동작을 멈춥니다. 기존 PNG와 캐시를 사용하며 이미지를 새로 분할하거나 변형하지 않습니다. [검증 방법과 결과](PERFORMANCE.md).

## 필드 활동 메시지

좌하단 반투명 기록창에 개인 활동을 최신순으로 표시합니다(PC 최대 3개, 모바일 세로 최대 2개·가로 최대 1개). 전체 저장 버퍼는 최근 8개이며 수첩의 기록 메뉴도 유지합니다. 메시지는 지도 클릭을 통과시키고 모바일 조작 패드 위에 배치됩니다. 각 플레이어의 행동·피격·파견·구조 기록을 분리하고 계정 저장/불러오기와 재시작 때 보존합니다. 이전 버전의 공유 기록은 플레이어별로 소급 분리하지 않습니다.

## 0.8.0 · 순찰·지역 난도·장비 전리품

- 인간·뱀파이어 NPC는 거점 반경 1.8, 몬스터는 출현 지점 반경 3에서 순찰합니다. 적은 거리 4.8 안에서 추적하며 출현 지점에서 10 이상 벗어나면 복귀합니다. 아지트 반경 7 안의 플레이어는 보호됩니다.
- 외곽 Lv.1–3 → 숲 Lv.4–6 → 저지대 Lv.8–10 → 공업지대 Lv.12–14. 몬스터 이름·레벨·실제 최대 체력을 표시합니다. 이동 메뉴에서 사냥터 위험도를 확인할 수 있습니다.
- 처치 경험치로 전투 Lv.1–20 성장. 기존 무기 강화 +0~10과 별도이며 강화·종족·기존 자산을 유지합니다.
- 전리품은 처치 즉시 가방에 자동 보관됩니다. 무기·방어구에 일반/고급/희귀/영웅/전설 등급을 적용하고, 가방 → 장비에서 능력치 비교·착용·해제가 가능합니다. 착용 장비가 실제 공격/방어에 반영됩니다. 바닥 아이템 줍기는 구현하지 않습니다.
- 처치당 장비 확률은 일반 5%, 고급 1%, 희귀 0.1%, 영웅 0.01%, 전설 0.001%. 장비 없음 93.889%. 치료제 20%는 별도 판정이며 기존 주문서 3·부품 2 보상을 유지합니다. 리니지의 공식 수치가 아닌 자체 초기 밸런스입니다.
- 새 저장 필드는 기존 저장에 한 번 추가합니다. 진행 중인 적의 체력·재생성 시각을 보존하며 새 최대 체력은 재생성 시 적용합니다. [상세 수치](DATA_AND_BALANCE.md).

## 인게임 아트워크

[아트 방향](ART_DIRECTION.md)과 [자산 목록](../ASSETS.md)에 출처와 범위를 기록합니다.

## 상황별 UI

지도와 간단한 체력·생활 지표를 기본 표시합니다. 생존·보관품·수첩·이동 버튼으로 한 분류씩 열며, 모바일에서는 하단 패널로 표시합니다. 인벤토리는 전체·재료·소모품·강화, 수첩은 첫 생존·의뢰·기록으로 나뉩니다.

아지트 메뉴는 서버의 이용 반경 7 안에서만 표시됩니다. 제작·시설·연구·파견을 선택하고, 제작 안에서는 요리·연금·치료 중 한 조합식과 재료/시설 조건을 표시합니다. 이탈·이동·접속 해제 때 관련 메뉴를 닫으며, 원거리 제작 등은 서버에서도 거절합니다. 즉시 이주·구조·이동 형태 사용은 이동 메뉴에서 유지합니다. 메뉴를 열어도 자동 일시정지하지 않습니다.

## 탐험 화면

256×256 맵에 외곽·소나무숲·저지대·공업지대 4개 지역, 기본 자원/NPC 29곳과 전문 탐색 장소 48곳, 지역별 전투원 35개체가 있습니다. 자원 ID를 유지하고 위치는 넓게 재배치했습니다. 인간은 루미나(36,38), 뱀파이어는 생귀스(176,46)에서 시작합니다. 기존 저장은 플레이어·아지트 좌표를 한 번 변환하고 몬스터 체력·진행도·자산을 유지합니다. 캐릭터를 따라가는 카메라와 65~160% 줌, 전체 미니맵 클릭 이동, 넓게 보기를 제공합니다.

WASD/방향키는 화면 방향으로 이동합니다. 클릭/탭 목적지 이동·도착 후 1회 채집/공격, 아지트 귀환 이동, Esc 취소, 작은 화면의 방향패드를 지원합니다. 나무·물가·폐허는 장식이며 지형 충돌·길찾기는 없습니다. 미니맵에 탐험 전 지역도 표시됩니다.

필드 그래픽은 원본 PNG 스프라이트와 Canvas 합성, 메뉴는 생성 일러스트와 CSS를 사용합니다. 이미지 로딩 실패 시 기존 도형 렌더러로 대체합니다. 관리는 분류형 메뉴로 열고, 첫 생존 안내를 수첩에 유지합니다. 저장 레이아웃 표식을 사용해 좌표 변환이 반복 적용되지 않도록 합니다.

## 실제 동작

서버가 이동 범위·속도·재료·시설 거리·강화·공격을 판정합니다. 사람/뱀파이어 선택, 자원 채집 6종, NPC 5명, 5회 채집 반복 의뢰, 수프·혈액·약초·안정화 혈액·치료제, 시설 4종 건설, 안전 지점으로 아지트 즉시 이동, 파견 보상, 물림 감염·치료·긴급 복구, 의료실의 양방향 종족 변환, 무기 강화 +10을 사용할 수 있습니다.

SQLite로 저장하고 재시작 시 복구합니다. 1개 브라우저 세션에 조작 권한을 임대합니다. 닫힘/숨김 후 약 1.2초 안에 월드 시간 정지, 다른 탭은 마지막 활동 4초 후 권한 획득 가능. 정지 버튼은 서버 시간을 멈춥니다.
