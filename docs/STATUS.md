# 현재 구현 상태 · P0

전체 GDD v0.7과 실행 코드 사이의 차이를 공개하는 문서입니다. P0는 게임 완성도가 아니라 생활 루프·저장 구조를 검증하는 단계입니다.

## 실제 동작

서버가 이동 범위·속도·재료·시설 거리·강화·공격을 판정합니다. 사람/뱀파이어 선택, 자원 채집 6종, NPC 2명, 5회 채집 반복 의뢰, 수프·혈액·약초·안정화 혈액·치료제, 시설 4종 건설, 안전 지점으로 아지트 즉시 이동, 파견 보상, 물림 감염·치료·긴급 복구, 의료실의 양방향 종족 변환, 무기 강화 +10을 사용할 수 있습니다.

SQLite로 저장하고 재시작 시 복구합니다. 1개 브라우저 세션에 조작 권한을 임대합니다. 닫힘/숨김 후 약 1.2초 안에 월드 시간 정지, 다른 탭은 마지막 활동 4초 후 권한 획득 가능. 정지 버튼은 서버 시간을 멈춥니다.

## 간략화된 부분

| 시스템 | 현재 동작 | 목표와 차이 |
| --- | --- | --- |
| 하우징 | 깃발과 4종 시설 레벨 | 자유 벽·가구·층별 배치 없음 |
| 인벤토리 | 휴대·창고 통합 단일 저장소 | 적재량·물리 화물·약탈과 분리 필요 |
| 농사/물 | 자원 노드에서 즉시 수확 | 파종·생장·빗물·정수 장치 없음 |
| 시설 | Lv.1이 조합식 해금, Lv.2~3 기록 | 상위 효율 효과 없음 |
| NPC | 고정 보급관 2명, 두 종족 모두 이용 | 적대·평판·거래·생활 AI 없음 |
| 종족 변환 | 의료실에서 약초·물로 양방향 전환 | 적대 혈화·정화 타이머 없음 |
| 좀비화 | 100 도달 시 아지트 복구·자산 보존 | 좀비 시체 생성·화물 이전 없음 |
| 강화 | 캐릭터의 단일 무기 수치 | 장비별 옵션·계승·크레딧 비용 없음 |
| 파견 | 60초, 완료 시 자동 보관 | 모집·부상·수령 UI 없음 |
| 인간 이동 | 부품 1개 탑승 비용, 이동 배율 | 실제 연료·차량 객체·화물 없음 |
| 뱀파이어 이동 | 박쥐 모양·이동 배율·혈액 소비 | 고도·장애물·착지·운반구 없음 |
| 월드 시간 | 활동 600초를 UI의 하루로 표시 | 주간 정산·수면 없음 |
| 연결 | HTTP 명령+400ms 조회 | 목표의 WSS 스트림은 후속 |
| 접근 | 운영자 키로 하나의 월드 조작 | 사용자 계정·복구 코드·개별 저장 없음 |

## 아직 없음

멀티/PvP, 실제 원거리 총격, 강화좀비·돌연변이, 던전·주간 제한, GPU 채굴, 연료·전력, 교역·약탈·해전, 소리·음악, 아트 에셋, 실내 가림·층·충돌 지형, 모바일 터치 조작. 공개 인터넷 상용 운영 수준의 인증·부하 제어·보안 강화도 미완성입니다.

## P0 종료 조건

양 종족 각각 자원 확보→기초 소모품 제작·섭취→시설 성장, 아지트 이동 및 종족 복귀 후 보존, 브라우저 재접속과 서버 재시작 후 저장 복원을 검증합니다. 다음 기능은 ROADMAP 순서로 추가합니다.
