# 데이터와 초기 수치

수치 출처는 `server/game.py`, 지도와 이동 상수는 `server/worldmap.py`. GDD 목표와 다른 부분은 STATUS에 명시합니다.

## 레시피

| 결과 | 비용 | 필요 시설 |
| --- | --- | --- |
| 수프 1 | 작물 2 + 식수 1 | 주방 Lv.1 |
| 안정화 혈액 1 | 원혈 2 + 약초 1 + 식수 1 | 연금대 Lv.1 |
| 치료제 1 | 약초 3 + 식수 2 | 의료실 Lv.1 |

수프: 포만 +45/수분 +15. 식수: 수분 +40. 원혈: 혈액 +30. 강화혈액: 혈액 +40/안정도 +45. 치료제: HP +40/감염 -60. 지표 상한 100.

생활 지표는 활동 초당 0.035 감소, 감염은 이미 감염된 경우 초당 0.025 증가. 프로토타입 시간과 실제 플레이 테스트를 위한 값이며 최종 밸런스 아님. 노드는 3초마다 자원 3개와 주문서 1개를 줍니다.

## 시설·강화

시설 다음 레벨 n: 목재 3n + 부품 2n, 최고 Lv.3. Lv.2~3 효율 효과는 후속 구현.

| 현재 강화 | 성공률 | 주문서 | 연속 실패 후 확정 |
| --- | --- | --- | --- |
| 0~2 | 100% | 1 | 즉시 |
| 3~5 | 80% | 2 | 2회 실패 다음 |
| 6~8 | 60% | 3 | 3회 실패 다음 |
| 9 | 40% | 5 | 4회 실패 다음 |

공격 피해 = (기본 공격 24 또는 회전 베기 32 + 착용 무기 능력치 + (전투 레벨−1)×2) × (1 + 강화 단계×0.02). 강화는 캐릭터의 공통 무기 숙련도로 장비 교체 시 유지됩니다. 실패 시 하락·파괴 없음. 현재 방어구 개별 강화와 화폐 비용은 없음.

## 원정·파견·이동

128×128 월드, 이동 좌표 범위 1~126. 사각 경계 없는 지역 중심 4곳, 자원/NPC 29곳, 감염체 11개체. 아지트 제작·보호 반경 7, 장식 비우기 반경 9. 기본 보폭은 명령당 0.48, 서버 최소 간격 0.10초, 클라이언트 전송 간격은 최소 140ms입니다. 대각선 입력은 서버에서 정규화하므로 월드 보폭이 늘어나지 않습니다.

감염체 Lv.n: HP = 60+(n−1)×18, 공격 = 8+(n−1)×2 / 2.5초, 감염 +5. 받는 피해 = max(1, 공격−착용 방어구 능력치). 추적 반경 4.8, 출현 지점 이탈 한도 10, 아지트 보호 반경 7. 처치 후 월드 활동 45초에 최대 체력으로 재생성. 순찰 속도 0.65칸/초, 추적 0.8, 강제 복귀 0.9. NPC 순찰 반경 1.8, 몬스터 3. 일시정지·접속 중단 시 활동 시간이 멈춥니다.

파견 60초: 목재 5·부품 3·주문서 5·원혈 3·작물 3. 비용은 인간 작물1/뱀파이어 원혈1. 보상 자동 보관, 반복 자동 출발 없음.

이동 연구: 인간 부품 5×다음단계+목재3, 뱀파이어 원혈5×다음단계+약초3. 인간 탑승은 부품1 소모하는 임시 대체 규칙. 박쥐 시작 혈액3, 이동 명령당 혈액0.18. 속도 배율 1.8/2.05. 상위 형태 미정.

## 저장 스키마

`world.version=1`. revision, elapsed, paused, player, base, inventory, cooldowns, dispatch, quest, enemies, log. SQLite `world(id PRIMARY KEY, value TEXT)`. 스키마 변경 시 버전 증가와 migration을 같이 작성합니다. 다른 버전은 자동 삭제하지 않고 오류로 중지합니다.

0.3.0 확장은 기존 version=1 구조를 유지하며, 저장에 없는 새 지역 감염체 ID만 추가합니다. 이전 자산을 초기화하거나 감염체 상태를 덮어쓰지 않습니다.

## 지역·전투 성장·전리품 (0.8.0)

지역 레벨 범위는 외곽 1–3, 숲 4–6, 저지대 8–10, 공업지대 12–14. 개체 레벨은 지역 최소 레벨 + 개체 ID % 3입니다. 기존 밀도를 유지하므로 모든 정수 레벨의 개체가 존재하지는 않습니다.
처치 경험치 12+몬스터 레벨×4, 다음 전투 레벨 필요 경험치 = 현재 전투 레벨×40. 잔여 경험치 이월, 최고 Lv.20에서 경험치 0 고정. 회복·체력 상한은 기존 100 유지.

| 등급 | 처치당 절대 확률 | 추가 능력치 |
| --- | --- | --- |
| 일반 | 5% | 0 |
| 고급 | 1% | 3 |
| 희귀 | 0.1% | 7 |
| 영웅 | 0.01% | 12 |
| 전설 | 0.001% | 20 |

합산 장비 확률 6.111%, 미획득 93.889%. 1회 처치에 장비 최대 1개, 무기/방어구 각 50%. 확률은 모든 지역 동일하며 천장·확률 누적 없음. 전설 평균 10만 회당 1개는 보장 횟수가 아닙니다. 서버 `server/equipment.py`가 판정하며 리니지 공식 수치가 아닙니다. 치료제는 독립적으로 20%, 주문서 3·부품 2는 확정. 모두 가방에 자동 보관합니다.

장비 T = 1+floor((몬스터 레벨−1)/4). 무기는 4T+등급 추가 능력치, 방어구는 2T+등급 추가 능력치. 전투 레벨/종족 착용 제한 없음. 무기와 방어구 각각 1개 착용하며 교체·해제해도 가방에 남습니다. 종류는 검/방호복 두 가지이며 랜덤 부가 옵션·매각·바닥 드롭은 후속 구현입니다.

저장에 `encounter_version=1`, `npcs`, `gear`, `equipment`, `next_gear_id`, `player.combat_level/xp`를 추가합니다. 기존 `player.level`은 강화 수치입니다. 장비에는 고유 ID·등급·부위·이름·능력치, 적에게는 레벨·최대 HP·공격력·경험치·복귀 상태를 저장합니다. 0.7 이전 저장에 새 필드만 한 번 추가하고 기존 체력·재생성 시각·강화·시설·재고를 유지합니다. 미지원 encounter_version은 삭제 없이 로드를 거절합니다.
