# 결정 기록

## 제품 결정

- D01: 생존·하우징 중심. 진영 전쟁은 선택적 자원·도전 콘텐츠.
- D02: 인간 음식/물/요리, 뱀파이어 원혈/연금 강화혈액의 지속 공급.
- D03: 종족은 복귀 가능. 아지트·연구·개인 자산 유지.
- D04: 아지트 이동에 운송·호송·비용·장시간 대기 없음.
- D05: 2D 쿼터뷰. 픽셀 아트 여부 미정.
- D06: 싱글 우선, 향후 소규모 멀티. 시즌·과금 없음.
- D07: 링크 접속 웹게임, 개인 PC 서버. 오프라인 로컬 게임 가정 폐기.
- D08: 인간 오토바이→험비→상위, 뱀파이어 변신술 박쥐→거대박쥐→상위.
- D09: 강화 주문서는 일반 활동에서 충분히 공급.

## P0 기술 결정 (장기 스택 확정 아님)

- T01: Python 3.11+ 표준 라이브러리 + Canvas. 설치와 레포 시작을 단순화.
- T02: SQLite JSON snapshot. 작은 월드에서 저장 정합성을 먼저 검증. 확장 시 엔티티별 테이블 전환.
- T03: HTTP polling, 목표의 WSS와 다름. 복잡한 통신보다 규칙·저장 검증 우선.
- T04: 하나의 개인 월드/캐릭터. 접근 키와 조작 임대는 계정 시스템이 아님.
- T05: 자유 건축·농사·차량 물리·멀티는 미구현으로 표시. 가짜 완료 상태를 만들지 않음.
- T06: 종족 변경을 의료실 버튼으로 제공해 자산 유지 경로를 먼저 테스트. 적대 전환 규칙은 P2.
- T07: 인간 연료를 부품 1개 탑승 비용으로 임시 대체. 이후 연료·차량 객체 필요.
- T08: 외부 배포 주소·사용자 GitHub 레포·포트는 임의 생성/수정하지 않음.
