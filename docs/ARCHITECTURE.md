# 아키텍처

## 현재 구조

- `public/app.js`: 상태 UI, 화면 방향 입력과 목적지 이동. `public/world.js`: 추적 카메라·보간·화면 영역만 그리는 Canvas 지형·소품·미니맵. 외부 CDN·폰트 의존 없음. `public/gothic.js`의 원본 도형 아트를 합성합니다.
- `public/art/`: 프로젝트용 생성 이미지 원본. `public/gothic.css`가 시작 화면·초상·아지트에 적용하며 서버는 지정된 파일만 허용합니다.
- `server/worldmap.py`: 맵 크기·지역·자원·감염체 원점·이동 상수. API의 `map` 메타데이터로 클라이언트에 전달.
- `server/game.py`: 월드 생성, 명령 검증, 생활·감염·NPC tick. HTTP/저장과 분리.
- `server/storage.py`: SQLite JSON snapshot 한 행. 저장 버전 검증, 단일 거래 commit.
- `server/main.py`: 정적 파일 허용 목록, 접근 키, 세션 임대, 요청 처리, 10Hz tick.
- `tests/`: 규칙·저장·실제 HTTP 경계 테스트.

서버가 결과를 확정합니다. 클라이언트는 dx/dy 또는 의도를 보내며 재료·좌표·HP·강화 결과를 직접 쓰지 못합니다. 명령은 잠금 안에서 월드의 복사본에 적용하고, 성공한 경우 DB commit 후 메모리를 교체합니다. 실패한 명령의 부분 재료 차감은 반영하지 않습니다.

## 시간과 저장

10Hz tick에서 실제 단조 시간 차이를 최대 1초로 제한합니다. 연결 heartbeat가 1.2초 이상 없거나 일시정지면 시간이 멈춥니다. 창을 숨기면 클라이언트 조회도 중단합니다. 서버가 꺼진 시간은 계산하지 않습니다.

명령은 즉시 저장하고 tick 변화는 2초마다 저장합니다. 정상 종료는 최종 저장합니다. 갑작스러운 전원 차단 시 마지막 성공 명령은 보존되지만 최대 약 2초의 연속 시뮬레이션 변화가 소실될 수 있습니다. 완전한 무손실 서버를 주장하지 않습니다.

## 동시성/재전송

명령 revision은 성공 명령마다 +1. 같은 revision의 반복 명령은 409로 거절합니다. tick은 revision을 증가시키지 않습니다. 따라서 revision은 틱별 화면 버전이 아니라 명령 적용 횟수입니다. 단일 프로세스 잠금과 SQLite 트랜잭션으로 요청·tick이 동시에 같은 자원을 쓰지 않도록 합니다. 이 구조는 1인 프로토타입용입니다.

같은 접근 키를 가진 여러 탭도 서로 다른 세션 ID를 사용합니다. 활성 세션은 마지막 접근 4초까지 다른 세션을 막습니다. 이 임대는 멀티 인증을 대체하지 않으며 공유 키를 가진 사용자는 임대 만료 후 같은 캐릭터를 제어할 수 있습니다.

## 확장 방향

1. 규칙 테스트를 유지하면서 world snapshot을 캐릭터·시설·아이템 ID 기반 데이터로 분리.
2. HTTP polling을 WSS로 변경하고 서버 tick과 클라이언트 보간 분리.
3. 플레이어별 인증·캐릭터·권한·관심 영역 동기화 추가.
4. 지형/충돌, NPC AI, 실내 가림, 자원 경제 확장.

Python 표준 라이브러리만으로 실행되는 점을 첫 프로젝트 편의로 선택했습니다. 장기 웹 엔진 선택을 확정한 것은 아닙니다. 생산용 HTTP 계층으로 교체해도 game.py와 저장 규칙은 재사용할 수 있습니다.

## 0.3.0 저장 호환

월드 JSON 형식은 version=1을 유지합니다. `Store.load()`는 알려진 감염체 ID 중 저장에 없는 새 지역 개체만 추가합니다. 기존 감염체의 체력·위치·재생성 시각, 플레이어·시설·자산·진행은 유지합니다. 반복 저장·재시작 시 중복 생성하지 않습니다. 지역 메타데이터는 저장 파일이 아닌 서버에서 제공합니다.

## 상황별 메뉴

`public/app.js`는 한 개의 modeless dialog 안에서 선택한 분류만 표시합니다. 메뉴를 열면 이전 이동을 취소하고, 새 이동 시 메뉴를 닫습니다. 아지트 전용 분류는 `map.base_radius`와 최신 서버 위치로 표시 여부를 계산하며, 경계 이탈이나 접속 해제 시 닫힙니다. 메뉴는 월드를 자동으로 일시정지하지 않습니다. 제작 UI는 서버 `recipes` 메타데이터를 사용하며, 버튼 표시와 별개로 모든 제작·자원 차감은 기존 서버 규칙에서 검증합니다.
