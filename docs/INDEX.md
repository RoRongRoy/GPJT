# 프로젝트 문서 인덱스

기준: GDD v0.7 / prototype 0.1.0 / 2026-10-26.

1. README → 실행과 첫 플레이.
2. REQUIREMENTS → 무엇이 확정인지.
3. GDD → 장기 제품 설계 전체.
4. STATUS → 현재 실행 코드가 어디까지인지.
5. ARCHITECTURE / API / DATA_AND_BALANCE → 구현 구조.
6. DEPLOYMENT / SAVE_AND_BACKUP → 개인 PC 운영.
7. ROADMAP / TEST_PLAN / DECISIONS → 다음 작업과 판단 근거.

**해석 우선순위:** 사용자 최신 결정 → REQUIREMENTS의 확정 사항 → GDD 목표 → STATUS의 현재 구현. GDD의 목표 수치를 실행 코드가 모두 충족한다고 해석하지 않습니다. 충돌이 생기면 구현을 숨기지 말고 STATUS와 결정 기록을 갱신합니다.

GDD는 기존 원본 전체를 보존했습니다. 과거 문서 파일명에 v0.1이 포함되어 있었지만 실제 본문은 v0.7이며, 이 레포에서는 `GDD.md`로 이름을 정리했습니다. 원본에 포함된 기존 게임명은 참고 경험이며 해당 게임의 자산·코드를 포함하지 않습니다.
