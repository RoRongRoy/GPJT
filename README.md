# BLOODFALL · 격리구역

**싱글 생존·하우징 중심의 2D 쿼터뷰 웹게임 프로토타입.** 개인 PC에서 서버를 실행하고 브라우저 링크로 접속합니다. 시즌·과금은 없습니다.

현재 버전은 **P0 / 0.8.0**입니다. GDD v0.7의 모든 기능을 구현한 완성 게임이 아닙니다. 전체 기획과 개발 문서는 포함하며, 실행 코드는 핵심 생활 루프를 검증하는 수직 단면입니다. 프로젝트 전용으로 생성한 건물·나무·시설 스프라이트, 인간/뱀파이어·감염체의 방향별 보행 프레임과 석재·흙 지형 텍스처를 Canvas 쿼터뷰 필드에 사용합니다.

## 바로 실행

Python **3.11 이상**이 필요합니다. 런타임 외부 패키지와 npm 설치는 필요하지 않습니다.

Windows: `start.bat`을 더블 클릭하면 서버와 브라우저가 열립니다. Python 3.11 이상이 먼저 설치되어 있어야 합니다. 또는 레포 루트에서:

```powershell
py -3 -m server.main
```

macOS / Linux:

```sh
python3 -m server.main
```

콘솔에 나온 `http://127.0.0.1:8080/#key=...` 링크를 브라우저에 붙여 넣습니다. 링크의 키는 이 프로토타입 월드의 접근 권한입니다. 공개 레포·스크린샷에 올리지 마세요. 키는 `data/access.key`, 저장은 `data/world.sqlite3`에 자동 생성됩니다. 두 파일 모두 Git 제외 대상입니다.

로컬 실행 링크는 다른 PC에서 접근할 공개 주소가 아닙니다. 외부 링크와 HTTPS 설정은 [개인 PC 배포 안내](docs/DEPLOYMENT.md)를 따라 별도로 준비합니다. 현재 기본 HTTP 서버는 비공개 개발용이며 인터넷 공개 서비스가 완성된 상태는 아닙니다.

## 첫 플레이 5분

1. 인간 또는 뱀파이어를 선택합니다. 선택은 서버에 저장됩니다.
2. 아지트 옆에서 **아지트 → 시설**로 주방 또는 연금대를 건설합니다. **아지트 → 제작**에서 요리·연금을 선택해 제작하고, **생존** 메뉴에서 섭취합니다.
3. 자원 지점을 **클릭/탭하면 이동 후 1회 채집**합니다. WASD 이동과 **E** 채집도 가능합니다. 일반 채집에도 강화 주문서가 나옵니다.
4. 자원 채집 5회 후 가까운 보급관 또는 연금사 근처에서 **E**로 반복 의뢰를 완료합니다.
5. 아지트 근처에서 **아지트 → 연구·성장 / 파견 / 시설**을 선택합니다. **이동 → 아지트 이주**로 안전한 현재 위치에 아지트를 즉시 옮길 수 있습니다.
6. 감염체 근처에서 Space로 공격합니다. 물렸다면 치료제 또는 위급 구조를 이용합니다.
7. 의료실을 만들면 인간↔뱀파이어 전환을 시험할 수 있습니다. 아지트는 유지됩니다.

`M`: 연구한 이동 형태 사용/해제. `일시정지`: 서버 월드 정지. 브라우저를 닫거나 숨기면 마지막 heartbeat 이후 약 1.2초 안에 활동 시간이 멈춥니다. 서버는 접속을 기다립니다.

## 0.3.1 분류 메뉴

- 기본 화면에는 지도와 간단한 생존 정보만 표시합니다. **생존·보관품·수첩·이동**을 눌러 필요한 분류 하나만 엽니다.
- **아지트 메뉴는 아지트 이용 범위(7) 안에서만 표시**됩니다. 제작·시설·연구·파견을 각각 선택하며, 벗어나면 열린 아지트 메뉴도 닫힙니다.
- 제작은 **요리·연금·치료**로 나뉩니다. 한 조합식의 재료 보유량/필요량, 시설 조건을 확인하고 1개씩 제작합니다.
- 보관품은 재료·소모품·강화, 수첩은 첫 생존·의뢰·기록으로 나뉩니다. 아지트 이주와 구조는 이동 메뉴에 있어 탐험 중에도 이용할 수 있습니다.
- `H` 생존, `I` 보관품, `J` 수첩, `B` 아지트. `Esc`로 닫거나 상위 분류 화살표로 돌아갑니다. 이동을 시작하면 메뉴가 닫힙니다.
- 메뉴를 열어도 월드 시간은 흐릅니다. 멈추려면 상단 일시정지를 사용하세요.

## 0.3.0 탐험·조작·디자인 개선

- **128×128 월드**: 0.6.0의 64×64 대비 4배 면적. 부드럽게 이어지는 외곽·소나무숲·저지대·공업지대, 굽은 길, 자원/NPC 29곳과 감염체 11개체를 넓게 분산합니다.
- 캐릭터 추적 카메라, 전체 미니맵 클릭 이동, 마우스 휠/버튼 확대·축소, `V` 넓게 보기.
- WASD/방향키가 **화면 방향**으로 이동합니다. 버튼 클릭 후에도 이동 가능하며, `Esc`·창 전환·일시정지로 이동을 취소합니다.
- 키보드·터치 방향패드는 누르고 있는 동안 연속 이동합니다. **Shift**를 누르거나 달리기 버튼을 켜면 1.65배 속도로 달리며, 키를 놓으면 즉시 정지 자세로 돌아옵니다. 직접 이동하면 자동사냥을 해제합니다. 보행 프레임과 발동작은 실제 이동 거리에 맞춰 재생합니다.
- 클릭한 자원에 도착하면 1회 채집. 작은 화면에는 길게 누르는 방향패드가 표시되며 손을 떼면 정지합니다.
- 지역별 지형·식생·시설을 Canvas로 표현하고, 캐릭터를 가리는 물체는 반투명하게 표시합니다.
- 탐험 지도 중심 화면, 생존 상태, 분류별 관리 메뉴, 첫 생존 안내.
- 기존 캐릭터·시설·보관품·진행 기록은 유지하며, 옛 저장에는 새 지역 감염체만 추가합니다.

장식 나무·물가·폐허에는 충돌이나 길찾기가 없습니다. 이동은 직선이며 미니맵은 전체 지역을 표시합니다.

## 검사

레포 루트에서 실행합니다.

```sh
python -m unittest discover -s tests -v
python tools/check_docs.py
node --check public/app.js
node --check public/world.js
node --check public/gothic.js
node tests/client_navigation.cjs
node tests/field_art.cjs
node tests/combat_effects.cjs
# 선택 성능 측정 (Playwright/Chromium 필요)
node tests/render_performance.cjs
```

Node는 JavaScript 문법·클라이언트 자동 검사에 쓰며 게임 실행에는 필요하지 않습니다. GitHub push·PR마다 서버/클라이언트 및 실제 브라우저 검사를 자동 실행합니다. main의 모든 검사를 통과하면 연결된 Linux 서버에 자동 배포할 수 있습니다. 서버를 한 번 연결하는 방법과 무료 VM/PC 운영 조건은 [자동화 안내](docs/AUTOMATION.md)를 참고하세요. Playwright와 Chromium이 있는 환경에서는 `node tests/browser_smoke.cjs`로 임시 월드를 사용한 실제 브라우저 검사를 실행할 수 있습니다. [검증 기록](docs/VALIDATION.md)을 참고하세요.

## 인벤토리와 기본 전투

화면 메뉴의 **가방** 또는 **I**로 아이콘 슬롯을 엽니다. 전체·재료·소모품·강화 탭을 선택하고 슬롯을 클릭하면 설명, 수량, 효과가 표시됩니다. 소모품은 상세 창의 **1개 사용**으로 사용합니다. 종족 제한·일시정지·수량을 확인하며 제작과 강화는 아지트 메뉴에서 수행합니다. 슬롯의 빈 칸은 표시용이며 새 용량 제한이나 장비 장착 시스템은 아닙니다.

- **Space / 공격 버튼**: 가장 가까운 적에게 기본 공격. 대상이 없을 때도 휘두르기는 가능합니다.
- **1~6 / 스킬 아이콘**: 스킬창(K)에서 배치한 스킬 사용. 새 설정은 여섯 칸 모두 비어 있으며, 습득한 스킬만 직접 등록합니다. 새 스킬을 해금해도 자동 등록하지 않습니다.
- **K → 스킬 키 설정**: 스킬의 `슬롯에 배치`를 누르고 1~6번 네모 슬롯을 선택하거나, 스킬 아이콘을 슬롯에 드래그합니다. 슬롯을 먼저 선택해도 됩니다. 기존 등록 스킬은 서로 자리를 바꾸며, 슬롯을 선택하고 **선택 슬롯 해제**를 누르면 빈칸으로 돌아갑니다. 빈칸을 클릭하면 해당 칸의 설정창을 엽니다. 배치와 빈칸은 브라우저에 자동 저장됩니다. 이전 배치에서는 습득한 스킬만 유지하고 미습득 스킬은 비웁니다.

탑승·변신 중에는 전투 스킬을 사용할 수 없습니다. 기본 공격과 베기는 0.6초 공격 대기를 공유합니다. 피해·소모·보상·쿨다운은 서버가 확정하며 연출은 승인 후 재생됩니다. 게임 화면은 등록한 스킬의 아이콘과 재사용 대기 가림 효과만 표시하며, 스킬명·상세 효과·단축키 배치는 스킬창에서 확인합니다. 키 배치는 브라우저 설정이며 계정 간 자동 동기화는 지원하지 않습니다.

필드는 전체 화면으로 표시합니다. 좌상단 초상·HP/MP, 좌측 생존 목표와 반투명 활동 기록, 우상단 메뉴·미니맵, 하단 중앙 스킬 퀵슬롯, 우하단 원형 전투 버튼·치료제/식수 바로 사용으로 구성합니다. 하단 경험치 막대는 실제 캐릭터 경험치를 표시하며, 모바일 세로·가로 화면에 맞춰 배치합니다.

추가 브라우저 검증: `node tests/combat_inventory_browser.cjs` (Playwright/Chromium 필요, 임시 저장 사용).


## 0.7.0 맵과 저장 전환

맵은 128×128이며 아지트 이용·보호 반경은 7칸입니다. 주변 9칸은 장식 나무·폐허를 비워두고 4종 시설을 서로 떨어뜨립니다. 자원/NPC 29곳과 몬스터 11개체는 수를 늘리지 않아 전체 면적당 밀도가 이전의 1/4입니다. 자원 간격은 최소 8칸 이상, 몬스터 출현 지점 사이는 17칸 이상입니다. 지역은 직사각형 구획 대신 영향 중심과 그라데이션으로 이어지며 지형 충돌은 여전히 없습니다.

이전 저장은 로드 시 `layout_version: 2`로 한 번 전환됩니다. 플레이어·아지트 좌표는 `기존 값 × 1.65 + 12`로 옮기고 몬스터는 새 출현 지점으로 재배치합니다. 아이템·시설·종족·강화·퀘스트·쿨다운·몬스터 체력/재생성 시간은 유지됩니다. 레이아웃 전환 후 저장을 이전 코드로 다시 열지 마세요. 직접 운영 중인 서버는 종료 후 `data/world.sqlite3`를 백업하고 업데이트하는 것을 권장합니다.

## 0.8.0 · 순찰·지역 난도·장비 전리품

- 인간·뱀파이어 NPC는 거점 반경 1.8, 몬스터는 출현 지점 반경 3에서 순찰합니다. 적은 거리 4.8 안에서 추적하며 출현 지점에서 10 이상 벗어나면 복귀합니다. 아지트 반경 7 안의 플레이어는 보호됩니다.
- 외곽 Lv.1–3 → 숲 Lv.4–6 → 저지대 Lv.8–10 → 공업지대 Lv.12–14. 몬스터 이름·레벨·실제 최대 체력을 표시합니다. 이동 메뉴에서 사냥터 위험도를 확인할 수 있습니다.
- 처치 경험치로 전투 Lv.1–20 성장. 기존 무기 강화 +0~10과 별도이며 강화·종족·기존 자산을 유지합니다.
- 전리품은 처치 즉시 가방에 자동 보관됩니다. 무기·방어구에 일반/고급/희귀/영웅/전설 등급을 적용하고, 가방 → 장비에서 능력치 비교·착용·해제가 가능합니다. 착용 장비가 실제 공격/방어에 반영됩니다. 바닥 아이템 줍기는 구현하지 않습니다.
- 처치당 장비 확률은 일반 5%, 고급 1%, 희귀 0.1%, 영웅 0.01%, 전설 0.001%. 장비 없음 93.889%. 치료제 20%는 별도 판정이며 기존 주문서 3·부품 2 보상을 유지합니다. 리니지의 공식 수치가 아닌 자체 초기 밸런스입니다.
- 새 저장 필드는 기존 저장에 한 번 추가합니다. 진행 중인 적의 체력·재생성 시각을 보존하며 새 최대 체력은 재생성 시 적용합니다. [상세 수치](docs/DATA_AND_BALANCE.md).


### 로컬 접속 키 오류

로컬에서는 `start.bat` 또는 `python -m server.main --open-browser`로 실행합니다. `http://127.0.0.1:8080/`이나 `http://localhost:8080/`에 키 없이 접속하면 이전 실행에서 탭에 남은 접속 키를 제거합니다. `#key=...`가 포함된 서버 콘솔 링크는 그 키를 우선 사용합니다. 서버를 재시작한 뒤 오래된 키가 붙은 주소를 열었다면 `#key=...` 부분을 지우고 새로고침하세요. 계정·캐릭터 저장은 삭제하지 않습니다.
