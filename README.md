# BLOODFALL · 격리구역

**싱글 생존·하우징 중심의 2D 쿼터뷰 웹게임 프로토타입.** 개인 PC에서 서버를 실행하고 브라우저 링크로 접속합니다. 시즌·과금은 없습니다.

현재 버전은 **P0 / 0.6.0**입니다. GDD v0.7의 모든 기능을 구현한 완성 게임이 아닙니다. 전체 기획과 개발 문서는 포함하며, 실행 코드는 핵심 생활 루프를 검증하는 수직 단면입니다. 프로젝트 전용으로 생성한 건물·나무·시설 스프라이트, 인간/뱀파이어·감염체의 방향별 보행 프레임과 석재·흙 지형 텍스처를 Canvas 쿼터뷰 필드에 사용합니다.

## 바로 실행

Python **3.11 이상**이 필요합니다. 런타임 외부 패키지와 npm 설치는 필요하지 않습니다.

Windows: `start.bat`을 더블 클릭하면 서버와 브라우저가 열립니다. Python 3.11 이상이 먼저 설치되어 있어야 합니다. 또는 레포 루트에서:

```powershell
py -3 -m server.main
```

macOS / Linux:

```sh
python3 -m server.main
```

콘솔에 나온 `http://127.0.0.1:8080/#key=...` 링크를 브라우저에 붙여 넣습니다. 링크의 키는 이 프로토타입 월드의 접근 권한입니다. 공개 레포·스크린샷에 올리지 마세요. 키는 `data/access.key`, 저장은 `data/world.sqlite3`에 자동 생성됩니다. 두 파일 모두 Git 제외 대상입니다.

로컬 실행 링크는 다른 PC에서 접근할 공개 주소가 아닙니다. 외부 링크와 HTTPS 설정은 [개인 PC 배포 안내](docs/DEPLOYMENT.md)를 따라 별도로 준비합니다. 현재 기본 HTTP 서버는 비공개 개발용이며 인터넷 공개 서비스가 완성된 상태는 아닙니다.

## 첫 플레이 5분

1. 인간 또는 뱀파이어를 선택합니다. 선택은 서버에 저장됩니다.
2. 아지트 옆에서 **아지트 → 시설**로 주방 또는 연금대를 건설합니다. **아지트 → 제작**에서 요리·연금을 선택해 제작하고, **생존** 메뉴에서 섭취합니다.
3. 자원 지점을 **클릭/탭하면 이동 후 1회 채집**합니다. WASD 이동과 **E** 채집도 가능합니다. 일반 채집에도 강화 주문서가 나옵니다.
4. 자원 채집 5회 후 가까운 보급관 또는 연금사 근처에서 **E**로 반복 의뢰를 완료합니다.
5. 아지트 근처에서 **아지트 → 연구·성장 / 파견 / 시설**을 선택합니다. **이동 → 아지트 이주**로 안전한 현재 위치에 아지트를 즉시 옮길 수 있습니다.
6. 감염체 근처에서 Space로 공격합니다. 물렸다면 치료제 또는 위급 구조를 이용합니다.
7. 의료실을 만들면 인간↔뱀파이어 전환을 시험할 수 있습니다. 아지트는 유지됩니다.

`M`: 연구한 이동 형태 사용/해제. `일시정지`: 서버 월드 정지. 브라우저를 닫거나 숨기면 마지막 heartbeat 이후 약 1.2초 안에 활동 시간이 멈춥니다. 서버는 접속을 기다립니다.

## 0.6.0 · Nocturne 아트워크

다크에덴 PC판의 고딕 도시·인간/뱀파이어 대비를 분위기 참고로 삼아 **BLOODFALL용 신규 아트**를 적용했습니다.

- 폐성당 도시 키 아트, 인간 생존자와 뱀파이어 초상 3장. 생성 이미지 원본과 출처를 저장소에 포함합니다.
- 종족 선택 화면, 종족 전환에 따라 바뀌는 생존자 초상, 아지트 삽화.
- 석조 피난처·고딕 폐허·가스등·고사목, 코트 실루엣과 차가운 포장 지형을 Canvas로 표현합니다.
- 분류형 메뉴와 아지트 전용 제작 흐름을 유지하고 흑철·황동·핏빛 색상으로 통일했습니다.

## 0.3.1 분류 메뉴

- 기본 화면에는 지도와 간단한 생존 정보만 표시합니다. **생존·보관품·수첩·이동**을 눌러 필요한 분류 하나만 엽니다.
- **아지트 메뉴는 아지트 이용 범위(2.8) 안에서만 표시**됩니다. 제작·시설·연구·파견을 각각 선택하며, 벗어나면 열린 아지트 메뉴도 닫힙니다.
- 제작은 **요리·연금·치료**로 나뉩니다. 한 조합식의 재료 보유량/필요량, 시설 조건을 확인하고 1개씩 제작합니다.
- 보관품은 재료·소모품·강화, 수첩은 첫 생존·의뢰·기록으로 나뉩니다. 아지트 이주와 구조는 이동 메뉴에 있어 탐험 중에도 이용할 수 있습니다.
- `H` 생존, `I` 보관품, `J` 수첩, `B` 아지트. `Esc`로 닫거나 상위 분류 화살표로 돌아갑니다. 이동을 시작하면 메뉴가 닫힙니다.
- 메뉴를 열어도 월드 시간은 흐릅니다. 멈추려면 상단 일시정지를 사용하세요.

## 0.3.0 탐험·조작·디자인 개선

- **64×64 월드**: 기존 22×22 대비 약 8.5배 면적. 외곽·소나무숲·저지대·공업지대, 자원/NPC 지점 29곳, 감염체 11개체.
- 캐릭터 추적 카메라, 전체 미니맵 클릭 이동, 마우스 휠/버튼 확대·축소, `V` 넓게 보기.
- WASD/방향키가 **화면 방향**으로 이동합니다. 버튼 클릭 후에도 이동 가능하며, `Esc`·창 전환·일시정지로 이동을 취소합니다.
- 클릭한 자원에 도착하면 1회 채집. 작은 화면에는 길게 누르는 방향패드가 표시되며 손을 떼면 정지합니다.
- 지역별 지형·식생·시설을 Canvas로 표현하고, 캐릭터를 가리는 물체는 반투명하게 표시합니다.
- 탐험 지도 중심 화면, 생존 상태, 분류별 관리 메뉴, 첫 생존 안내.
- 기존 캐릭터·시설·보관품·진행 기록은 유지하며, 옛 저장에는 새 지역 감염체만 추가합니다.

장식 나무·물가·폐허에는 충돌이나 길찾기가 없습니다. 이동은 직선이며 미니맵은 전체 지역을 표시합니다.

## 이 빌드에서 되는 것

- 서버 권한 이동·채집·제작·소모·강화·기본 근접 전투.
- 양 종족 생활 지표, 수프/강화혈액, 간단한 감염·치료·복구.
- 시설 레벨 0~3, 아지트 즉시 이동, 전환·복귀 시 자산 보존.
- 주문서 강화 +10, 실패 누적 보정, 반복 의뢰·60초 파견.
- 오토바이/험비·박쥐/거대박쥐 **속도 체험용 연구**.
- SQLite 저장, 재시작 복구, 비공개 링크 키, 1개 브라우저 조작 임대.

현재 인벤토리는 휴대품과 아지트 창고를 합친 단일 저장소입니다. 시설 상위 레벨은 기록되지만 생산 효율 차이는 아직 없습니다. 상세 차이는 [구현 상태](docs/STATUS.md)에 있습니다.

## 검사

레포 루트에서 실행합니다.

```sh
python -m unittest discover -s tests -v
python tools/check_docs.py
node --check public/app.js
node --check public/world.js
node --check public/gothic.js
node tests/client_navigation.cjs
node tests/field_art.cjs
node tests/combat_effects.cjs
# 선택 성능 측정 (Playwright/Chromium 필요)
node tests/render_performance.cjs
```

Node는 JavaScript 문법·클라이언트 자동 검사에 쓰며 게임 실행에는 필요하지 않습니다. GitHub Actions도 포함되어 있습니다. Playwright와 Chromium이 있는 환경에서는 `node tests/browser_smoke.cjs`로 임시 월드를 사용한 실제 브라우저 검사를 실행할 수 있습니다. [검증 기록](docs/VALIDATION.md)을 참고하세요.

## 인벤토리와 기본 전투

하단 **인벤토리** 또는 **I**로 아이콘 슬롯을 엽니다. 전체·재료·소모품·강화 탭을 선택하고 슬롯을 클릭하면 설명, 수량, 효과가 표시됩니다. 소모품은 상세 창의 **1개 사용**으로 사용합니다. 종족 제한·일시정지·수량을 확인하며 제작과 강화는 아지트 메뉴에서 수행합니다. 슬롯의 빈 칸은 표시용이며 새 용량 제한이나 장비 장착 시스템은 아닙니다.

- **Space / 공격 버튼**: 가장 가까운 적에게 기본 공격. 대상이 없을 때도 휘두르기는 가능합니다.
- **Q / 첫 번째 스킬 버튼**: 회전 베기(뱀파이어: 혈월 베기). 반경 2.7 안의 적에게 기본 피해 32, 재사용 5초, 포만도 또는 혈액량 6 소모.
- **R / 두 번째 스킬 버튼**: 숨 고르기(뱀파이어: 혈액 재생). 체력 18 회복, 재사용 10초, 포만도 또는 혈액량 8 소모.

탑승·변신 중에는 전투 스킬을 사용할 수 없습니다. 기본 공격과 베기는 0.6초 공격 대기를 공유합니다. 피해·소모·보상·쿨다운은 서버가 확정하며 연출은 승인 후 재생됩니다. 베기에는 기존 무기 강화 배율이 적용됩니다. 별도 스킬 트리·마나·장비 슬롯은 아직 없습니다.

추가 브라우저 검증: `node tests/combat_inventory_browser.cjs` (Playwright/Chromium 필요, 임시 저장 사용).
