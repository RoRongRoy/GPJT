# BLOODFALL · 격리구역

**싱글 생존·하우징 중심의 2D 쿼터뷰 웹게임 프로토타입.** 개인 PC에서 서버를 실행하고 브라우저 링크로 접속합니다. 시즌·과금은 없습니다.

현재 버전은 **P0 / 0.1.0**입니다. GDD v0.7의 모든 기능을 구현한 완성 게임이 아닙니다. 전체 기획과 개발 문서는 포함하며, 실행 코드는 핵심 생활 루프를 검증하는 수직 단면입니다. 플레이스홀더 그래픽을 사용합니다.

## 바로 실행

Python **3.11 이상**이 필요합니다. 런타임 외부 패키지와 npm 설치는 필요하지 않습니다.

Windows: `start.bat`을 더블 클릭하거나 레포 루트에서:

```powershell
py -3 -m server.main
```

macOS / Linux:

```sh
python3 -m server.main
```

콘솔에 나온 `http://127.0.0.1:8080/#key=...` 링크를 브라우저에 붙여 넣습니다. 링크의 키는 이 프로토타입 월드의 접근 권한입니다. 공개 레포·스크린샷에 올리지 마세요. 키는 `data/access.key`, 저장은 `data/world.sqlite3`에 자동 생성됩니다. 두 파일 모두 Git 제외 대상입니다.

로컬 실행 링크는 다른 PC에서 접근할 공개 주소가 아닙니다. 외부 링크와 HTTPS 설정은 [개인 PC 배포 안내](docs/DEPLOYMENT.md)를 따라 별도로 준비합니다. 현재 기본 HTTP 서버는 비공개 개발용이며 인터넷 공개 서비스가 완성된 상태는 아닙니다.

## 첫 플레이 5분

1. 인간 또는 뱀파이어를 선택합니다. 선택은 서버에 저장됩니다.
2. 아지트 옆에서 주방 또는 연금대를 건설합니다. 인간은 수프, 뱀파이어는 안정화 혈액을 제작·섭취합니다.
3. WASD로 자원 지점에 접근하고 **E**로 채집합니다. 일반 채집에도 강화 주문서가 나옵니다.
4. 자원 채집 5회 후 인간 보급관 또는 혈족 연금사 근처에서 **E**로 반복 의뢰를 완료합니다.
5. 아지트에서 장비 강화·파견·시설 개선을 시험합니다. 안전한 위치에서 아지트를 즉시 옮길 수 있습니다.
6. 감염체 근처에서 Space로 공격합니다. 물렸다면 치료제 또는 위급 구조를 이용합니다.
7. 의료실을 만들면 인간↔뱀파이어 전환을 시험할 수 있습니다. 아지트는 유지됩니다.

`M`: 연구한 이동 형태 사용/해제. `일시정지`: 서버 월드 정지. 브라우저를 닫거나 숨기면 마지막 heartbeat 이후 약 1.2초 안에 활동 시간이 멈춥니다. 서버는 접속을 기다립니다.

## 이 빌드에서 되는 것

- 서버 권한 이동·채집·제작·소모·강화·기본 근접 전투.
- 양 종족 생활 지표, 수프/강화혈액, 간단한 감염·치료·복구.
- 시설 레벨 0~3, 아지트 즉시 이동, 전환·복귀 시 자산 보존.
- 주문서 강화 +10, 실패 누적 보정, 반복 의뢰·60초 파견.
- 오토바이/험비·박쥐/거대박쥐 **속도 체험용 연구**.
- SQLite 저장, 재시작 복구, 비공개 링크 키, 1개 브라우저 조작 임대.

현재 인벤토리는 휴대품과 아지트 창고를 합친 단일 저장소입니다. 시설 상위 레벨은 기록되지만 생산 효율 차이는 아직 없습니다. 상세 차이는 [구현 상태](docs/STATUS.md)에 있습니다.

## 검사

레포 루트에서 실행합니다.

```sh
python -m unittest discover -s tests -v
python tools/check_docs.py
node --check public/app.js
```

Node는 JavaScript 문법 검사에만 쓰며 게임 실행에는 필요하지 않습니다. GitHub Actions도 포함되어 있습니다.

## 첫 레포 업로드

새 빈 원격 레포를 만든 뒤 **이 폴더 안**에서 실행합니다. 아래 마지막 명령은 사용자가 선택한 원격 주소로 바꿉니다.

```sh
git init
git add .
git commit -m "Initial Bloodfall survival prototype"
git branch -M main
git remote add origin <YOUR_REPOSITORY_URL>
git push -u origin main
```

레포는 이 패키지에서 생성하거나 업로드하지 않았습니다. 사용자의 라이선스 결정 없이 MIT 등 공개 재사용 라이선스를 임의 부여하지 않았습니다. 재배포 정책은 [LICENSE_POLICY.md](LICENSE_POLICY.md)를 확인하세요.
